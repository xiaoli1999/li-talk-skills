# 让页面好改：写页面的结构规范

用户会在浏览器里直接改课件：单击选中一块、拖动、拖角缩放，双击改字，改字号和颜色，再点「通知 AI 修改」交给你合进源码（`serve`，见 SKILL.md「在线编辑」一节）。

编辑器按页面「画出来的样子」找元素，不挑写法，结构乱一点也能改。照下面写，用户点哪儿就选中哪儿，改一处不牵动别处，你合并时也能一眼在源码里找到它。

写页面（⑥ ⑦ ⑧）时照这份写；样板页都已经照它写好，照样板抄就不会错。

---

## 1. 一段字一个元素

要单独改的每一段字（标题、副题、讲者、日期、标签、数字）各自放进一个元素里。

```html
<!-- 好：讲者和日期各是一个元素，用户可以只改日期 -->
<div class="cv-badge abs" data-beat="1" style="left:1240px;top:640px;width:540px">
  <p class="cv-name">讲者：〈你的名字〉</p>
  <p class="cv-date">〈日期〉</p>
</div>

<!-- 不好：两段字挤在一个元素里，用空格或 <br> 分开，只能一起改 -->
<div class="cv-badge abs">讲者：〈你的名字〉<br>〈日期〉</div>
```

- 一句话里的重点词、单位、小号字（`<em class="key">`、`<small>`、`<b>`）留在这句话里面，它们是这句话的一部分。
- 编辑器认「一段字」的办法：里面只有字和跟着字排在行里的行内标签。`display:block`、`inline-block`、`flex` 或绝对定位的 `<b>`、`<span>` 都算单独的一段。所以讲者和日期要分开排时，写成两个元素，再用 CSS 让它们各占一行。

## 2. 字号写在文字自己身上，行内小字用 em

```css
[data-id="p01"] .cv-name{font-size:44px}
[data-id="p01"] .cv-name small{font-size:.6em}   /* 好：外面放大，小字跟着按比例变 */
[data-id="p01"] .cv-name small{font-size:26px}   /* 能改，但合并时要多改一处 */
```

- 用户改的是「这段字」的字号，写在文字元素自己的类名上最好找。
- 写在外面容器上、让里面的字继承，也能改，只是合并时要你去找它从哪儿继承来的。
- 颜色一律写变量（`var(--ink)`、`var(--accent)`），用户在调色板上选的就是这些变量（见 `authoring.md` 第 5 节「颜色一律用变量」）。

## 3. 能单独拖动的块，带一个「前缀-名字」的类名

用户单击时，编辑器选中鼠标下面最近的一「块」。下面这些算一块：

- 带 `data-beat`、`.abs`、`.card`、`.shot`、`data-mascot` 的元素；
- 类名是「前缀-名字」的元素：前缀是 1 到 6 个小写字母或数字，比如 `cv-name`、`p05-tip`、`fg-chip`。

一段字想让用户单独拖动、单独缩放，就给它一个这样的类名。没有类名的 `<p>` 会被当成外层那一块的一部分：点它就选中外层，拖动时整块一起走。

页面私有的类名用页号做前缀（`p05-tip`），合并时写 CSS 也用它：`[data-id="p05"] .p05-tip{…}`。

## 4. 上下排的几行用排版流，不用固定高度卡死

- 同一张卡片里上下排的几行，用普通排版流（`<p>` 一个接一个）或 `display:flex;flex-direction:column`。用户放大其中一行时，编辑器会保持后面的行不动（预览时给它加 `margin-bottom` 抵消）。合并时清单里会写「给它写 margin-bottom:Npx」，照写。
- 卡片不写死 `height`，要高度就写 `min-height`：字变多、变大时，卡片跟着长，不会溢出。
- 不要用一堆绝对定位的子元素拼一段字（一行字拆成几个 `position:absolute` 的 span），用户改字号时它们会各走各的。

## 5. 要讲的字写在 html 里，不用 CSS 或脚本生成

- 字写在 `Deck.add` 的 `html` 里，用户改了你才能在源码里按原文找到它。
- 不要用 CSS 的 `content:"…"`、`attr(data-xxx)`，也不要在 `onBeat` 或风格脚本里用 `innerHTML` 写要讲的字。这样生成的字，编辑器改不到，合并时也找不到原文。
- 装饰性的符号（引号、箭头、编号的圆点）用 CSS 生成可以，它们不是要改的内容。

## 6. 位置写 left、top，旋转和缩放写变量

- 绝对定位的块，行内 `style` 只写 `left`、`top`、`width`（需要时 `height`），旋转写风格给的变量（比如 `--r:-2deg`）。用户拖动后，你直接改这几个数。
- 不要在行内 `style` 或章节 CSS 里给内容块写 `transform`：编辑器的预览、出场动画都用 `translate`、`scale` 属性，写死的 `transform` 会和它们打架。要放大一块，写 `scale:1.2`（见 SKILL.md 的合并规则「整块缩放」）。

## 7. 图片和截图放进 `.shot`

截图用 `figure.shot`，说明写在 `data-caption` 里（见 `authoring.md` 第 5 节「截图位」）。用户拖角改大小时，图片按比例缩放、不变形。

---

## 写完自查

- 页面上每段要讲的字，双击都能单独改，改了不会带上旁边的字。
- 想让用户单独拖动的块，都有「前缀-名字」类名或 `data-beat`、`.abs`。
- 没有用 CSS `content` 或脚本写要讲的字；内容块上没有写死的 `transform`。
