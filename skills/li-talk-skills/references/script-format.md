# 讲稿格式（讲稿.md）

讲稿是课件目录里的 `讲稿.md`。先有讲稿、用户确认了，才开始写页面：页面上的每一个字、每一拍出现什么、形象走到哪，都从讲稿里来。讲稿错了，页面就得整页重写；所以讲稿要写得具体，给用户确认时用户一眼能看出对不对。

这份说明讲三件事：文件开头的提纲怎么写、每页的四段格式怎么写、规则和原因。最后有两页完整的示例。

---

## 1. 为什么格式要固定

格式不是为了好看，脚本和页面都靠它：

| 写法 | 谁靠它 | 写错了会怎样 |
|---|---|---|
| 每页的标题行写成 `## 第 N 页 页标题` | `guide` 靠它数讲稿有几页，判断「写全稿」做完没有、还差哪几页 | 页数数不出来，`guide` 会说「数不出讲稿有几页」 |
| 讲词写在 `**讲词**` 这一行的后面 | `guide` 靠它数讲词字数、估算时长 | 字数算成 0，时长估不出来 |
| 讲词按 `【第 0 拍】`、`【第 1 拍】` 分段 | 写页面时一拍对应一条 `notes`，演讲者视图按拍显示 | 讲者按一下不知道该说哪段 |
| 开头写 `## 给组织方` 提纲 | `guide` 靠它判断提纲写了没有 | `guide` 会说「讲稿.md 里还没有提纲」 |
| 提纲里写 `时间与时长：20 分钟，……` | `guide` 靠它算讲词的目标字数 | 算不出目标字数，讲稿写多长只能自己估 |

要点：`## 第 N 页` 里的 `N` 用阿拉伯数字，从 1 开始，一页一个，不跳号、不重复；`第`、`页` 两个字不能省。

---

## 2. 文件开头：标题和提纲

第一行是一级标题（课件标题），下面是一节「给组织方」。提纲这一节在 ② 提纲这一步写，用户确认后运行 `confirm <课件目录> outline`；之后讲稿接在它后面写，提纲留着不删。

照这个格式写（〈 〉和 …… 换成真实内容）：

```markdown
# 〈课件标题〉

## 给组织方
- 一句话简介：……
- 适合谁听：……
- 时间与时长：……（讲多久，在什么场合、什么屏幕上讲）
- 听完能带走什么：……
- 大纲：
  1. 〈第一部分〉（约 N 页）：这部分讲什么
  2. 〈第二部分〉（约 N 页）：……
- 合计：约 N 页
```

- 页数按时长估：大约每分钟 1 页，20 分钟约 20 页。第一页是封面，最后一页是结尾，都算在内。
- 「时间与时长」写成「20 分钟」这样带数字的说法；有问答时写成「40 分钟（讲 35 分钟）」，按讲的那个数算。`guide` 靠它算讲词的目标字数（见第 4 节「时长怎么估」）。
- 「适合谁听」「时间与时长」「听完能带走什么」用用户回答的原话，别自己编。用户没说的，`guide` 会给出要问的问题。
- 这一节也可以直接发给活动的组织方当简介，所以写成完整的句子。

## 3. 每一页：四段格式

每页一个 `## 第 N 页 页标题`，下面依次是：两行页头、**屏幕**、**节拍**、**画面**、**讲词**。

```markdown
## 第 N 页 页标题

章节标记：……　风格：……
主题：章节短名 › 本页主题

**屏幕**（投出来的字，原样使用）
- 主题行：章节短名 › 本页主题
- 标题：……
- 一句话解释：……（新概念第一次出现的页才有）
- ……（点击复制的内容写成一行代码，后面注明「（点击复制）」）
- 图注：……（有截图、截图下面要一行说明时才写；不要写成「截图说明：」）

**节拍**（拍数 = 翻到这页后要点几下，第 0 拍不算）
- 第 0 拍：翻到这页就在的内容｜重点词：xx
- 第 1 拍：出现什么｜重点词：xx
- 第 2 拍：出现什么｜重点词：xx

**画面**（怎么画、怎么动、形象做什么；要用截图的写明用哪张）

**讲词**（照着讲，不投出来；按拍分段，重点词加粗）
【第 0 拍】……
【第 1 拍】……
```

### 各段怎么写

**页头两行**

- `章节标记`：这页属于哪一章，写成「一、准备」这种带序号的章节名，同一章的页写成一模一样。写页面时它就是 `Deck.add` 的 `chapter`。
- `风格`：这页用哪种风格的键名（比如 `watercolor`）。③ 写讲稿时还没选风格，先写「（④ 选完风格再填）」；选定后统一补上。只用一种风格时每页都写同一个。
- `主题`：`章节短名 › 本页主题`。章节短名就是章节标记去掉「一、」这类序号；本页主题十几个字以内。封面和结尾可以不写主题。

**屏幕**（投出来的字，原样使用）

- 这里写的每一个字都会原样出现在页面上。写页面时不再改字，只决定摆在哪。
- `主题行`、`标题` 必写（封面、结尾可以没有主题行）。标题 20 个字以内，长了一行放不下。
- `一句话解释`：只在新概念第一次出现的那页写，格式「概念：大白话解释」，30 个字以内。
- 其余每一行是一块内容：一张卡片、一个步骤、一行命令。卡片写成「标题｜一句说明」，一张卡片两行以内。
- 要让观众点一下就复制的命令或网址，写成一行代码，后面注明「（点击复制）」，比如：`` `npm run dev`（点击复制） ``。
- 截图本身写在「画面」一段里。截图下面要显示一行说明时，写成「- 图注：……」（20 个字以内），写页面时放进截图位 `figure.shot` 的 `data-caption`，显示成图下面的小字。**不要写成「截图说明：……」当一行正文**；`素材/截图说明.md` 是给 AI 看的，里面的话不投出来。
- 屏幕上的字短而具体：一页正文不超过约 80 个字，放不下就拆成两页。

**节拍**

- 每一拍一行：`第 n 拍：这一拍出现什么｜重点词：xx`。第 0 拍是翻到这页就在的内容（标题、主题行、一句话解释），不用点。
- 讲者每按一下进一拍。**拍数 = 翻到这页后要点几下，第 0 拍不算**：第 0 拍 + 第 1、2 拍 = 2 拍；只写了第 0 拍和第 1 拍的是 1 拍。
- 每页 2 到 4 拍（写到第 2 拍到第 4 拍）；封面和结尾 1 到 2 拍（至少要有第 1 拍，比如副标题第 1 拍出现）。
- 每拍一个重点词。屏幕上有这个词，写页面时就把它标成重点词（`<em class="key">`）；屏幕上没有，就只在讲词里加粗。

**画面**（怎么画、怎么动、形象做什么）

- 用一两句话写版式：「三张卡片横排一行，一拍出一张」「三个步骤横排，中间用手绘箭头连起来」。
- 写形象做什么：「形象每拍站到当前这张卡片下面」「第 3 拍形象说『浇透』」。形象说的话写这一拍的重点词，2 到 4 个字。
- 要用截图时写文件名，文件名照 `素材/截图说明.md` 里的写，比如「右边放 素材/设置页.png，只露出上半部分」。
- 不确定怎么画时，挑一种样板页的版式（封面、清单、步骤、结尾，见 templates.md），写「照清单样板」也行。

**讲词**（照着讲，不投出来）

- 按拍分段：`【第 0 拍】……`、`【第 1 拍】……`，和「节拍」一段一一对上：第 0 拍也有一段，一拍一段，不多不少（2 拍的页有 3 段讲词）。
- 用第一人称、口语、短句；每拍三四句以内。
- 重点词加粗：`**排水孔**`。
- 讲词会进演讲者视图（讲者按 S 打开），观众看不到。

## 4. 规则和原因

1. **每页 2 到 4 拍（封面结尾 1 到 2 拍）；拍数 = 翻到这页后要点几下，第 0 拍不算。** 第 0 拍 + 第 1、2 拍 = 2 拍。讲一拍按一下，讲者才知道这页要点几下、讲到哪了，动效也才有人看到。超过 4 拍，说明这页塞了太多，拆成两页；不到 2 拍，就把已有内容分到第 1、2 拍出现，或和前后页合并，不要为了凑拍数加字。
2. **每页顶部一行主题。** 大标题常常是一句论点（「少浇勤看，比多浇好」），刚翻到这页的人光看标题不知道在讲什么；主题行告诉他「两种浇法」。
3. **新概念第一次出现的那页，第 0 拍先用一句大白话解释。** 听众跟不上，多半是一个词没听懂；第一次出现时就解释，后面的页不用再解释。
4. **每拍一个重点词，讲词里加粗，屏幕上有这个词就标出来。** 讲者扫一眼就知道这一拍要落在哪个词上；观众看到被强调的词，知道这一拍的重点。
5. **屏幕上的字短而具体；讲词用第一人称、短句，每拍三四句以内。** 投影上的字是给人「扫」的，不是给人「读」的；讲词是要说出口的，长句说不顺。
6. **不写没有依据的数字、百分比、案例和用户反馈。** 「效率提升 80%」「很多同事说好用」这类话，用户没给出处就不要写。拿不准就问用户，或者改成不带数字的说法。
7. **用总字数控制时长：目标字数 = 讲多久 × 每分钟 220 到 250 字。低于目标下限的 90% 先问用户怎么补，超过上限要删。** 到了上限再加内容，必须从别处减。
8. **不要为了凑字数加空话。** 补的每一句都要有具体内容：一个例子、一个步骤、一个数字。具体内容来自用户或素材；没有，就问用户，不能编。换个说法把上一句再说一遍、「这一步很重要」「大家可以想一想」这类没有新东西的句子，听众一听就知道是凑的，不算补。

### 时长怎么估

- 字数只算 `**讲词**` 后面的内容：汉字一个算一个字，英文单词、一串数字算一个字，标点和 `【第 n 拍】` 不算。
- 每分钟 220 到 250 字：5 分钟约 1100～1250 字，10 分钟约 2200～2500 字，20 分钟约 4400～5000 字，30 分钟约 6600～7500 字。讲多久看「给组织方」里的「时间与时长」，写了「40 分钟（讲 35 分钟）」就按 35 分钟算。
- **够不够的标准**：讲词低于目标下限的 90% 算不够，超过上限要删。比如讲 5 分钟，目标 1100～1250 字：低于 990 字算不够，超过 1250 字要删；990～1100 字差得不多，可以不补。
- **不够时先问用户，不要自己凑**：提纲里还有没写的页，先照提纲写完；页都写了还不够，就问用户怎么办（`guide` 会给出这个问题）：
  1. 把现有的页讲细：你列出哪几页可以展开、每页需要用户补什么具体内容（例子、步骤、数字），用户给了再写进讲词；
  2. 加几页新内容：你列出提纲里还能加的方向，请用户给要点，照要点加页，提纲也跟着改；
  3. 就讲这么短：把「给组织方」里的时长改成讲稿实际够讲的分钟数，页数跟着减。
- **不要为了凑字数加空话**：补的每一句都要有具体内容（例子、步骤、数字），来自用户或素材；没有就问用户，不能编。每拍仍在三四句以内。
- **怎么删**：先删讲词里重复的话，再合并内容少的页。大约每分钟 1 页，页数和时长要对得上。
- `guide` 在 ③ 讲稿这一步会算好：「讲 5 分钟：目标约 1100–1250 字，现在 883 字，还差约 217 字」；不到下限的 90% 时，【问用户】里会多一个「怎么办」的问题。搭好骨架后 `check` 也会按页面里的 `notes` 再估一次。

## 5. 讲稿怎么变成页面

写页面时一段对一处，照着搬，不用再想：

| 讲稿里 | 页面里（`Deck.add`，详见 authoring.md） |
|---|---|
| `## 第 5 页 页标题` | `id: 'p05'`，`title: '页标题'` |
| 章节标记「一、准备」 | `chapter: '一、准备'` |
| 主题「准备 › 要买的东西」 | `topic: '要买的东西'`（章节短名引擎自动从 chapter 里取） |
| 风格 | `scene: '风格键名'` |
| 屏幕的每一行 | `html` 里的文字，原样照抄 |
| 一句话解释 | `<p class="explain"><b>概念</b>：解释</p>` |
| 画面里的截图、屏幕里的「图注：……」 | `<figure class="shot" data-src="素材/xx.png" data-caption="图注的字">`，图注不另写成正文 |
| 节拍「第 n 拍：出现什么」 | 那块内容写 `data-beat="n"`；最大的 n 就是拍数（第 0 拍不算） |
| 重点词 | `<em class="key">词</em>`，讲词里的同一个词写进 `notes` 的 `key` |
| 画面里「形象站到…」 | 目标元素写 `data-mascot="n"` 和 `data-mascot-side` |
| 讲词【第 n 拍】 | `notes: [{ beat: n, key: '重点词', say: '这一拍的讲词' }]` |

## 6. 两页完整示例

虚构主题「阳台上种一盆小番茄」。先是文件开头，然后是第 3 页（清单）和第 8 页（图示）。

```markdown
# 阳台上种一盆小番茄

## 给组织方
- 一句话简介：从零开始，在自家阳台上种出一盆小番茄
- 适合谁听：没种过菜、家里有阳台的同事
- 时间与时长：午休时间，15 分钟，会议室投影
- 听完能带走什么：知道要买什么、怎么种下去、平时怎么照看
- 大纲：
  1. 开场（约 2 页）：封面，为什么挑小番茄
  2. 准备（约 4 页）：盆、土、种子，放在哪儿
  3. 动手（约 5 页）：泡种、播种、浇水
  4. 照看（约 3 页）：晒太阳、间苗、搭支架
  5. 结尾（约 1 页）：一句话收尾
- 合计：约 15 页

## 第 3 页 动手前，准备三样东西

章节标记：二、准备　风格：watercolor
主题：准备 › 要买的东西

**屏幕**（投出来的字，原样使用）
- 主题行：准备 › 要买的东西
- 标题：动手前，准备三样东西
- 一句话解释：育苗盆：底下带排水孔的小花盆
- 卡片 1：育苗盆｜底下要有排水孔
- 卡片 2：营养土｜花店买现成的
- 卡片 3：种子｜挑矮生品种

**节拍**
- 第 0 拍：标题、一句话解释｜重点词：育苗盆
- 第 1 拍：卡片 1 出现｜重点词：排水孔
- 第 2 拍：卡片 2 出现｜重点词：现成的
- 第 3 拍：卡片 3 出现｜重点词：矮生

**画面**（怎么画、怎么动、形象做什么；要用截图的写明用哪张）
三张卡片横排一行，颜色各不相同，一拍出一张，照清单样板。形象第 0 拍站在一句话解释的右边，之后每拍站到当前这张卡片的下面。不用截图。

**讲词**（照着讲，不投出来；按拍分段，重点词加粗）
【第 0 拍】动手之前，先把东西备齐。这里说的**育苗盆**，就是底下带排水孔的小花盆。
【第 1 拍】第一样是育苗盆。最要紧的是底下有**排水孔**，水多了能流走，根才不会泡坏。
【第 2 拍】第二样是营养土。花店就有，买**现成的**就行，别挖楼下的土，容易带虫。
【第 3 拍】第三样是种子。阳台地方小，挑包装上写着**矮生**的品种，长不太高。

## 第 8 页 种下去，只要三步

章节标记：三、动手　风格：watercolor
主题：动手 › 播种

**屏幕**（投出来的字，原样使用）
- 主题行：动手 › 播种
- 标题：种下去，只要三步
- 步骤 1：装土｜装到离盆口一指宽
- 步骤 2：播种｜撒在土面，盖层薄土
- 步骤 3：浇透水｜浇到盆底流出水

**节拍**
- 第 0 拍：标题｜重点词：三步
- 第 1 拍：步骤 1 出现｜重点词：装土
- 第 2 拍：步骤 2 和指向它的箭头出现｜重点词：播种
- 第 3 拍：步骤 3 和指向它的箭头出现｜重点词：浇透

**画面**（怎么画、怎么动、形象做什么；要用截图的写明用哪张）
三个步骤横排，带序号，中间用手绘箭头连起来；每拍出一步，箭头和这一步一起画出来，照步骤样板。形象每拍走到当前步骤的下面，第 3 拍说「浇透」。不用截图。

**讲词**（照着讲，不投出来；按拍分段，重点词加粗）
【第 0 拍】东西备齐了，种下去其实只要**三步**。
【第 1 拍】第一步**装土**。土装到离盆口一指宽，留点地方浇水。
【第 2 拍】第二步**播种**。种子撒在土面上，再盖一层薄薄的土。
【第 3 拍】第三步浇水，要**浇透**，一直浇到盆底流出水为止。
```

这两页对照上面的规则：

- 标题行都是 `## 第 N 页 页标题`，讲词都在 `**讲词**` 后面，按拍分段。
- 第 3 页有新概念「育苗盆」，所以第 0 拍有一句话解释；第 8 页没有新概念，就不写。
- 每页 3 拍（第 0 拍加第 1、2、3 拍，第 0 拍不算），讲词 4 段，每拍一个重点词。第 8 页第 0 拍的「三步」屏幕上没有单独这个词，就只在讲词里加粗。
