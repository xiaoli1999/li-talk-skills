# 风格说明

这一版有 6 种风格。每种风格是课件目录 `scenes/` 下的一对文件（`<键名>.js` 和 `<键名>.css`），所有风格共用同一套组件类名和 CSS 变量，所以同一页内容换个风格不用改结构，只是样子、出场动效、强调方式、形象的描边跟着变。

这份说明讲：怎么推荐和选、每种风格的样子和脾气、按章分配的规矩、搭好骨架后怎么换风格。`styles` 命令会列出同样的要点（样子、适合、不适合、注意、默认形象），这里写得更细。

---

## 1. 怎么推荐、怎么选

1. **按讲稿每部分讲什么挑。** 对照下面每种风格的「适合」，挑一个主推，跟用户说一句理由（比如「这份讲的是入门上手、听众不全是技术同事，推荐水彩田园」）。`guide` 在 ④ 风格这一步给的推荐是按讲稿里的词粗估的，你读过讲稿觉得别的更合适，就换成你的推荐。
2. **同时打开样册给用户看**：运行 `styles --open`。样册还没做好时它会说明，那就把 `styles` 的文字说明讲给用户听。
3. **用户说了算。** 样册里所有风格都能选，用户选了你没推荐的也照用。
4. **会议室投影要提醒一句**：深色底（黑板、科技暗黑）投到幕布上容易发灰，推荐前先跟用户说一声。
5. 用户明确选定后，运行 `confirm <课件目录> style --scenes <键名>`（多种用逗号隔开，见第 4 节），再往下搭骨架。

---

## 2. 三家

每种风格属于一家。同一家的风格用同一种字体、同一套手感，可以在一份课件里按章混用；不同家的不混。

| 家 | 字体 | 这一版有的风格 |
|---|---|---|
| 手绘家 | 楷书（霞鹜文楷） | 方格纸 `paper`、黑板 `board`、像素手账 `journal`、工位桌面 `desk`、水彩田园 `watercolor` |
| 现代家 | 系统黑体，命令用等宽字 | 科技暗黑 `dark` |
| 像素家 | 中文像素字体 | 这一版还没有 |

---

## 3. 六种风格

每种写了：样子、适合、不适合、脾气（禁区、配色限制、投影上的注意）、默认形象、动效。禁区里有字，自检会报「进了风格的禁区」；所有风格都把左上角的主题行（x 120–1380、y 18–78）和右上角的页码、节拍格（x 1340–1856、y 30–90 左右）算作禁区，下面不再重复。

### 手绘家

#### 方格纸 `paper`

- **样子**：浅色方格纸，左侧一列活页孔；墨色线框，黄色荧光笔划重点。带颜色的卡片是贴上去的便签，可复制的命令是一张翘起纸角的黄便签，「已复制」是绿笔打勾。
- **适合**：开场、总览、愿景、收尾。
- **不适合**：大段代码、密集数据。
- **脾气**：
  - 禁区：左边 x 66 以内是活页孔，内容别放进去（按左右各留 120px 写就不会碰到）。
  - 最干净的一种，只有一个强调色（荧光黄），别再加别的颜色；线条用 `svg.sketch` 画墨线框，不要满屏便签。
  - 没有挑浏览器的效果。
- **默认形象**：朵朵 `duoduo`（暂时借用，以后会有自己的形象）。
- **动效**：内容轻轻上浮，大标题一笔写出来；翻页时整张活页绕左侧的孔翻过去。

#### 黑板 `board`

- **样子**：干净的深绿板面，只有白粉笔和一支黄粉笔，字和线带粉笔的毛边；底下一条木头粉笔槽，槽里放着粉笔和一块板擦。重点词先白粉笔写、再黄粉笔描一遍。节拍格是板角的「正」字，五拍一个字。
- **适合**：基础教学、命令清单、安装步骤。
- **不适合**：要靠很多颜色区分的内容、大量截图、温情的故事。
- **脾气**：
  - 禁区：底部 y 1000 以下是粉笔槽，右边 x 1470–1620、y 978 起立着一块板擦。内容的底边留在 y 980 以上。
  - 只有白、黄两色：卡片颜色 `t-yellow` 是黄粉笔，`t-mint`、`t-pink`、`t-blue`、`t-peach` 一律变成白粉笔（不报错，只是看不出区别）。黄色只给重点词和圈注。
  - 别放大段小字：粉笔小字投影上最难认。一行一个要点，命令写大一点。
  - 深色底投到幕布上容易发灰，字和线已经加粗，讲过的拍也只淡一点（不像别的风格淡那么多）。
  - 最后一页用黑板时，署名会自动放在粉笔槽上面一点（y 950 左右），这一条要空出来。
- **默认形象**：朵朵 `duoduo`（深色底上引擎自动给它加一圈浅色描边）。
- **动效**：内容一笔一笔写出来，同一拍里先画线、再写字；退一拍时板擦把这一拍的内容擦掉；翻页时板擦把整块板擦一遍再写下一页。

#### 像素手账 `journal`

- **样子**：很淡的点阵纸，墨绿字，琥珀色荧光带划重点；正文是手写楷体，像素感只留给形象的对话框、「已复制」提示框和节拍格。复制成功时形象蹦一下喊「已复制！」，命令框变绿。
- **适合**：以角色为主线的章节、讲原理的示意图。
- **不适合**：严肃汇报、大段代码、密集数据。
- **脾气**：
  - 大标题 72px，比别的风格大一号，一句话解释跟着往下让到 y 200：标题 19 个字以内，长了会换行。
  - 别把卡片、按钮、文字做成像素风；卡片是细线框加很淡的底色。手绘图用细线框加斜线涂色。
  - 没有挑浏览器的效果。
- **默认形象**：朵朵 `duoduo`（暂时借用）。
- **动效**：字从左往右写出来，同时轻轻落下；翻页是默认的整页横移，像翻手账。

#### 工位桌面 `desk`

- **样子**：很淡的米色木纹桌面，内容是落在桌上的白纸和便签；纸胶带贴章节，珊瑚红马克笔划重点；可复制的命令是标签机打出来的黑条，「已复制」是一个红色印章；线稿带铅笔的毛边。
- **适合**：讲者自己的故事、多方协作。
- **不适合**：大段代码、密集数据、很正式的汇报。
- **脾气**：
  - 一切都是「纸落到桌上」：纸是白的、颜色很淡。文字尽量放在纸（卡片）上，别直接写在桌面上。
  - 珊瑚红只用在重点词、圈注、印章，别再加别的强调色。
  - 没有挑浏览器的效果。
- **默认形象**：朵朵 `duoduo`（暂时借用）。
- **动效**：纸从上面落到桌上（`drop`），命令条按标签机的样子一截一截打出来，大标题淡入；翻页时旧纸被推到一边，新的一张滑进来。

#### 水彩田园 `watercolor`

- **样子**：水彩纸底、淡蓝天、左上角暖阳、一朵积云、两层草坡和一条铅笔地平线；铅笔描线加水彩上色。卡片、小格、命令、金句的底色是一笔水彩，出场时颜色从一点洇开；重点词底下晕开一抹暖阳黄；节拍指示是一排小颜料点。
- **适合**：入门教程、上手流程、温和的分享、面向非技术同事。
- **不适合**：大段代码、表格图表、严肃话题。
- **脾气**：
  - 配色只有纸色、暖褐墨、铅笔灰，强调色是天空蓝和暖阳黄；草绿只属于背景和「自动」（`ai`）小格。页面 CSS 别再引入别的颜色。
  - 底部草坡不算禁区：颜色很淡，字压在上面也看得清。
  - 颜色洇开时每帧都要重算，配置差的电脑上翻拍可能有点卡。
- **默认形象**：朵朵 `duoduo`（本来就是这种风格的形象：一朵圆滚滚的水彩小积云）。
- **动效**：第一次打开时有约 1 秒的开场（天空晕开、草坡刷过去、标题逐字显出）；默认出场是「墨色显出」，大标题逐字显出，带颜色的组件水彩洇开；退一拍时水彩缩回去、字像墨被吸走一样淡去；翻页时一道水痕扫过。
- **自带出场名**：`ink`、`bloom`、`letters`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

### 现代家

#### 科技暗黑 `dark`

- **样子**：像产品发布会的暗色质感。近黑底加唯一的冷色冰蓝，背景有极淡的噪点和柔和光晕；卡片是深色缎面配 1px 渐变描边，银色渐变大标题；字用系统黑体（不是楷书），命令用等宽字。重点词被一道白光扫过、染成冰蓝；当前这一拍的组件描边会染成冰蓝。节拍指示是玻璃胶囊。
- **适合**：技术分享、命令行教学、发布会、产品介绍。
- **不适合**：温情人文、大段阅读、需要很多插图的内容。
- **脾气**：
  - 只有一个冷色：卡片颜色 `t-*` 在这里都是冰蓝或浅灰，靠颜色区分不了几张卡片，用标题和位置区分。
  - 深色底投到幕布上容易发灰，正文已经提亮到接近白；页面 CSS 里正文不要用比 `--ink-2` 更暗的颜色，线和字要亮、要粗一点。
  - 不要加发光线、HUD 角标、乱码这类显廉价的装饰。
  - 字体是黑体，同样的字比楷书略宽：从手绘家换过来时，原来刚好放下的字可能溢出，换完一定重跑自检。
  - 渐变描边在不支持的浏览器里退回普通描边，不影响内容。
  - 页码和节拍胶囊的禁区是 x 1340–1856、y 14–82。
- **默认形象**：微光 `weiguang`（悬浮的钛灰小方块机器人，一条冰蓝眼灯；自带亮边，引擎不再加描边）。
- **动效**：第一次打开时有开场（光晕亮起、主题行落下、大标题由虚到实）；文字默认「由虚到实」浮上来，卡片类组件浮起并有一道光沿描边扫过，命令柔边擦出；退一拍时字先虚化、组件再沉下去；翻页时旧页上收淡出、新页从下面浮上来。
- **自带出场名**：`focus`、`lift`、`wipe`、`sweep`。只在这种风格里认，页面里别写。

## 4. 按章分配风格

内容跨度大时（比如前面讲愿景、中间讲安装命令、后面讲故事），可以按章用不同的风格。规矩：

- **最多 3 种。** 多了像拼凑，讲者和观众都累。
- **只在同一家里混。** 这一版的手绘家有 5 种，可以互相搭；科技暗黑是现代家唯一的一种，只能单独用。跨家混用，`check` 和自检都会报「风格混用了不同的家」。
- **全稿统一的东西不变**：字体、强调色的用法、重点词的标法、节拍指示的位置、形象。一份课件只用一个形象，按章换风格时形象不跟着换。
- **同一章只用一种风格**，别在一章里来回换。

一个例子：开场和收尾用方格纸，讲安装命令的那章用黑板，讲上手流程的那章用水彩田园。

写法：

1. 确认风格时一次记下全部，第一种是主风格（形象跟着它走）：`confirm <课件目录> style --scenes paper,board,watercolor`。
2. 搭骨架时 `new` 照这个列表把几种风格都放进课件（`guide` 会给出完整命令）。
3. 每页的 `scene` 写这一章的风格：方格纸那几章写 `scene: 'paper'`，黑板那章写 `scene: 'board'`。

---

## 5. 临时看看别的风格

- 在浏览器地址栏 `index.html` 后面加 `?scene=键名`，整份课件临时全换成这种风格，不改任何文件。**只认这份课件里已经引入的风格**（`new` 只放进了选中的几种），没引入的会被忽略、照原样显示。
- 想看没引入的风格是什么样，用样册：`styles --open`。
- 用户看完 3 页试做想换风格，先打开样册比较，定了再照下一节真的换。

---

## 6. 搭好骨架后换风格

`new` 已经把选中的风格复制进了课件，`index.html` 里也写好了引入。之后用户要换风格，照下面 a–e 做。**这是唯一允许改 `index.html` 章节区以外的情况**，而且只改引入风格的那两行；平时写页面一律只改 `slides/` 和章节区。

下面的〈新风格〉〈旧风格〉换成键名（比如 board、paper），〈本 skill 目录〉是 SKILL.md 所在的目录，〈课件目录〉是这份课件的目录；`guide` 在 ④ 风格（已经搭好骨架时）和 ⑥ 先做 3 页（给用户看 3 页的时候）会给出填好路径的同一套命令，能直接复制。

a. 记下新风格（形象先不换，`--mascot` 后面写现在用的形象）：

```
node "〈本 skill 目录〉/scripts/li-talk.mjs" confirm "〈课件目录〉" style --scenes 〈新风格〉 --mascot 〈现在的形象〉
```

b. 把 `〈本 skill 目录〉/template/scenes/〈新风格〉.js` 和 `〈新风格〉.css` 复制到 `〈课件目录〉/scenes/`。

c. 把 `〈课件目录〉/index.html` 里 `scenes/〈旧风格〉.css`、`scenes/〈旧风格〉.js` 这两行的文件名换成新风格（只有换风格时才动章节区以外的这两行）。改完是这样：

```html
<link rel="stylesheet" href="scenes/〈新风格〉.css">
…
<script src="scenes/〈新风格〉.js"></script>
```

旧风格的两个文件留在 `scenes/` 里也没关系：`index.html` 不引入就不会加载。

d. 把 `〈课件目录〉/slides/` 里每页的 `scene: '〈旧风格〉'` 换成新风格。

e. 重跑后台自检，错误改到 0 个：

```
node "〈本 skill 目录〉/scripts/li-talk.mjs" check "〈课件目录〉" --browser
```

换风格后常见的变化：科技暗黑是黑体，字比楷书宽，可能溢出；像素手账的标题大一号；黑板底部有粉笔槽、颜色只剩白黄。所以第 e 步一定要做，报什么改什么。

补充两种情况（同样属于换风格，同样只动风格、形象的引入行）：

- **在原来的风格之外再加一种**（按章分配）：a 写上全部风格（`--scenes 旧风格,新风格`）；b 照做；c 改成在原来那两行下面各加一行新风格，原来的两行保留；d 只改要换的那几章。
- **用户也想换形象**（比如换成科技暗黑后想用微光）：把 `〈本 skill 目录〉/template/mascots/〈新形象〉.js` 复制到 `〈课件目录〉/mascots/`；`index.html` 里 `<script src="mascots/〈旧形象〉.js">` 这一行换成新形象，`<meta name="li-talk-mascot" content="〈旧形象〉">` 的 content 也换成新形象；第 a 步的 `--mascot` 写新形象。这一版的形象只有朵朵 `duoduo` 和微光 `weiguang`。
