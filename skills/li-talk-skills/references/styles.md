# 风格说明

这一版有 16 种风格，分成四类。每种风格是课件目录 `scenes/` 下的一对文件（`<键名>.js` 和 `<键名>.css`），所有风格共用同一套组件类名和 CSS 变量，所以同一页内容换个风格不用改结构，只是样子、出场动效、强调方式、形象的描边跟着变。

这份说明讲：怎么推荐和选、每种风格的样子和脾气、按章分配的规矩、搭好骨架后怎么换风格。`styles` 命令会列出同样的要点（样子、适合、不适合、注意、默认形象），这里写得更细。

---

## 1. 怎么推荐、怎么选

1. **按讲稿每部分讲什么挑。** 对照下面每种风格的「适合」，挑一个主推，跟用户说一句理由（比如「这份讲的是入门上手、听众不全是技术同事，推荐水彩田园」）。`guide` 在 ④ 风格这一步给的推荐是按讲稿里的词粗估的，你读过讲稿觉得别的更合适，就换成你的推荐。
2. **样册给用户看**：`guide` 一到 ④ 风格就自动打开样册（每份课件一次），不用等用户开口；用户想再看就运行 `styles --open`。样册首页是全部风格的总览，点一张卡片就从第一页看这种风格。`guide` 的问题直接给 4 个选项（按推荐的、两个备选、先体验全部风格），原样问用户；用户选「先体验全部风格」，就等他看完说出风格名再确认。
3. **用户说了算。** 样册里所有风格都能选，用户选了你没推荐的也照用。
4. **方果 `fangguo` 是方果 ERP（深圳市渔童科技有限公司）的品牌风格**，每页左上角带方果 Logo，「关于我们」页带公司的二维码和联系方式：讲稿是方果同事给客户演讲、给领导汇报时推荐它，别的场合不推荐。
5. **会议室投影要提醒一句**：深色底（黑板、蓝图、科技暗黑、像素游戏）投到幕布上容易发灰，推荐前先跟用户说一声。
6. 用户明确选定后，运行 `confirm <课件目录> style --scenes <键名>`（多种用逗号隔开，见第 4 节），再往下搭骨架。

## 2. 四类

每种风格属于一类。同一类的风格字体、手感相近，可以在一份课件里按章混用；不同类的不混。

| 家 | 字体 | 这一版有的风格 |
|---|---|---|
| 企业风 | 系统黑体，数字用 Bahnschrift / DIN | 方果 `fangguo`（公司品牌专属，只能单独用） |
| 手绘风 | 楷书（霞鹜文楷） | 方格纸 `paper`、黑板 `board`、像素手账 `journal`、工位桌面 `desk`、水彩田园 `watercolor`、水墨国风 `ink`、蓝图 `blueprint`、漫画 `comic` |
| 现代风 | 系统黑体（杂志复古用宋体），命令用等宽字 | 科技暗黑 `dark`、毛玻璃 `frost`、液态玻璃 `glass`、扁平插画 `flat`、杂志复古 `magazine`、新粗野主义 `brutal` |
| 像素风 | 中文像素字体（缝合像素字体，选了才带进课件） | 像素游戏 `pixel` |

像素手账 `journal` 名字里有「像素」，但正文是楷书，属于手绘风；整页像素风的是像素风的像素游戏 `pixel`，它的字体和 4px 网格自成一套，只能单独用。

## 3. 十六种风格

每种写了：样子、适合、不适合、脾气（禁区、配色限制、投影上的注意）、默认形象、动效，有自带出场名的也列出来。禁区里有字，自检会报「进了风格的禁区」；所有风格都把左上角的主题行（x 120–1380、y 18–78）和右上角的页码、节拍格（x 1340–1856、y 30–90 左右）算作禁区，下面不再重复，范围和这个差得多的写在各自的脾气里。

### 手绘风

#### 方格纸 `paper`

- **样子**：浅色方格纸，左侧一列活页孔；墨色线框，黄色荧光笔划重点。带颜色的卡片是贴上去的便签，可复制的命令是一张翘起纸角的黄便签，「已复制」是绿笔打勾。
- **适合**：开场、总览、愿景、收尾。
- **不适合**：大段代码、密集数据。
- **脾气**：
  - 禁区：左边 x 66 以内是活页孔，内容别放进去（按左右各留 120px 写就不会碰到）。
  - 最干净的一种，只有一个强调色（荧光黄），别再加别的颜色；线条用 `svg.sketch` 画墨线框，不要满屏便签。
  - 没有挑浏览器的效果。
- **默认形象**：尖尖 `jianjian`（一截用短了的黄色六棱铅笔头，墨蓝铅笔线；深色底上引擎会给它加浅色描边）。
- **动效**：内容轻轻上浮，大标题一笔写出来；翻页时整张活页绕左侧的孔翻过去。

#### 黑板 `board`

- **样子**：干净的深绿板面，只有白粉笔和一支黄粉笔，字和线带粉笔的毛边；底下一条木头粉笔槽，槽里放着粉笔和一块板擦。重点词先白粉笔写、再黄粉笔描一遍。节拍格是板角的「正」字，五拍一个字。
- **适合**：基础教学、命令清单、安装步骤。
- **不适合**：要靠很多颜色区分的内容、大量截图、温情的故事。
- **脾气**：
  - 禁区：底部 y 1000 以下是粉笔槽，右边 x 1470–1620、y 978 起立着一块板擦。内容的底边留在 y 980 以上。
  - 只有白、黄两色：卡片颜色 `t-yellow` 是黄粉笔，`t-mint`、`t-pink`、`t-blue`、`t-peach` 一律变成白粉笔（不报错，只是看不出区别）。黄色只给重点词和圈注。
  - 别放大段小字：粉笔小字投影上最难认。一行一个要点，命令写大一点。
  - 深色底投到幕布上容易发灰，字和线已经加粗，讲过的拍也只淡一点（不像别的风格淡那么多）。
  - 最后一页用黑板时，署名会自动放在粉笔槽上面一点（y 950 左右），这一条要空出来。
- **默认形象**：沙沙 `shasha`（一截白粉笔头，黄粉笔腮红，手脚是粉笔线；白身子自带粉尘光，引擎不再加描边。别的形象放到黑板上，引擎会自动加一圈白粉笔色描边）。
- **动效**：内容一笔一笔写出来，同一拍里先画线、再写字；退一拍时板擦把这一拍的内容擦掉；翻页时板擦把整块板擦一遍再写下一页。

#### 像素手账 `journal`

- **样子**：很淡的点阵纸，墨绿字，琥珀色荧光带划重点；正文是手写楷体，像素感只留给形象的对话框、「已复制」提示框和节拍格。复制成功时形象蹦一下喊「已复制！」，命令框变绿。
- **适合**：以角色为主线的章节、讲原理的示意图。
- **不适合**：严肃汇报、大段代码、密集数据。
- **脾气**：
  - 大标题 72px，比手绘风别的风格大一号，一句话解释跟着往下让到 y 200：标题 19 个字以内，长了会换行。
  - 别把卡片、按钮、文字做成像素风；卡片是细线框加很淡的底色。手绘图用细线框加斜线涂色。想要整页像素风，用像素风的像素游戏 `pixel`。
  - 没有挑浏览器的效果。
- **默认形象**：点点 `diandian`（24×21 格的像素墨水瓶，琥珀瓶盖、墨绿墨水；引擎把它的落点取整到整数像素，边缘不虚）。
- **动效**：字从左往右写出来，同时轻轻落下；翻页是默认的整页横移，像翻手账。

#### 工位桌面 `desk`

- **样子**：很淡的米色木纹桌面，内容是落在桌上的白纸和便签；纸胶带贴章节，珊瑚红马克笔划重点；可复制的命令是标签机打出来的黑条，「已复制」是一个红色印章；线稿带铅笔的毛边。
- **适合**：讲者自己的故事、多方协作。
- **不适合**：大段代码、密集数据、很正式的汇报。
- **脾气**：
  - 一切都是「纸落到桌上」：纸是白的、颜色很淡。文字尽量放在纸（卡片）上，别直接写在桌面上。
  - 珊瑚红只用在重点词、圈注、印章，别再加别的强调色。
  - 没有挑浏览器的效果。
- **默认形象**：卷卷 `juanjuan`（一卷米白和纸胶带，珊瑚红细条纹，撕开的胶带头当尾巴；比别的形象宽，舞台上 181×162）。
- **动效**：纸从上面落到桌上（`drop`），命令条按标签机的样子一截一截打出来，大标题淡入；翻页时旧纸被推到一边，新的一张滑进来。

#### 水彩田园 `watercolor`

- **样子**：水彩纸底、淡蓝天、左上角暖阳、一朵积云、两层草坡和一条铅笔地平线；铅笔描线加水彩上色。卡片、小格、命令、金句的底色是一笔水彩，出场时颜色从一点洇开；重点词底下晕开一抹暖阳黄；节拍指示是一排小颜料点。
- **适合**：入门教程、上手流程、温和的分享、面向非技术同事。
- **不适合**：大段代码、表格图表、严肃话题。
- **脾气**：
  - 配色只有纸色、暖褐墨、铅笔灰，强调色是天空蓝和暖阳黄；草绿只属于背景和「自动」（`ai`）小格。页面 CSS 别再引入别的颜色。
  - 底部草坡不算禁区：颜色很淡，字压在上面也看得清。
  - 颜色洇开时每帧都要重算，配置差的电脑上翻拍可能有点卡。
- **默认形象**：朵朵 `duoduo`（本来就是这种风格的形象：一朵圆滚滚的水彩小积云）。
- **动效**：第一次打开时有约 1 秒的开场（天空晕开、草坡刷过去、标题逐字显出）；默认出场是「墨色显出」，大标题逐字显出，带颜色的组件水彩洇开；退一拍时水彩缩回去、字像墨被吸走一样淡去；翻页时一道水痕扫过。
- **自带出场名**：`ink`、`bloom`、`letters`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

#### 水墨国风 `ink`

- **样子**：宣纸底，左下两层淡墨远山；全页只有墨色浓淡加一点朱砂。卡片是浅纸册页配细墨线，标签和命令是线装书的题签（外粗内细的双线框）；带序号的步骤是一个个墨点，竖着排时一笔飞白竖画把墨点串起来；重点词到拍时转成朱砂，每个字下面朱笔圈一个小圈；复制命令后盖一枚白文朱印「已复制」。节拍指示是一排墨点。
- **适合**：人文、方法论、流程讲解，开场和收尾要有仪式感的时候。
- **不适合**：信息很密的页、要科技感或热闹气氛的场合。
- **脾气**：
  - 配色只有墨色三层（浓 `--ink`、中 `--ink-2`、淡 `--ink-3`）和朱砂；卡片颜色 `t-*` 在这里都是深浅不同的纸色，区分不了几张卡片，用标题和位置区分。页面 CSS 别再引入别的颜色。
  - 淡墨小字投到偏暗的幕布上会发淡：正文已经加深，页面里正文不要用比 `--ink-2` 更淡的颜色。
  - 左下的远山不算禁区：墨色很淡，字压在上面也看得清。
  - 横排步骤不画竖笔，只有墨点，步骤之间的连接靠页面自己画的手绘箭头；竖排步骤自动用竖笔串起来，不用画箭头。
  - 形象用了 SVG 滤镜，换姿势时要重画一次。
- **默认形象**：墨丸 `mowan`（一滴落在宣纸上的墨，眉心一粒朱砂）。
- **动效**：第一次打开时有约 1 秒的开场（远山浮出、大标题墨晕洇出，形象落地时脚下洇开一圈淡墨）；文字默认从左边墨晕洇出，卡片、命令、终端、截图像卷轴一样展开；步骤一步步出来时竖笔往下写、墨点落下溅墨；悬停时一团淡墨从鼠标处洇开；退一拍时墨晕往回收；翻页时新页像墨一样从一边洇开。
- **自带出场名**：`yun`、`zhan`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

#### 蓝图 `blueprint`

- **样子**：深蓝晒图纸、很淡的细白网格，四周一圈双线图框和分区刻度。线只有白和浅青两种；卡片、小格、终端、截图位、命令都画成「零件」：直线方角、实心深蓝底、白描边，卡片右上角有零件编号、右下露出一道斜线阴影，截图位顶上一道尺寸标注线，命令是一块双框铭牌。重点词转橙色、底下画两道橙色细线；复制命令后盖一枚橙色审图章「已复制」。节拍指示是右上角的「装配」加一排装配步骤编号。
- **适合**：搭建、组成、架构，把一个东西拆成几块讲。
- **不适合**：温情故事、大量照片、要靠很多颜色区分的内容。
- **脾气**：
  - 只有白和浅青两种线色：卡片颜色 `t-yellow`、`t-blue` 是浅青描边，其余是白或很浅的青白，区分不了几张卡片，用标题、位置和零件编号区分。橙色只给重点词、当前步骤、审图章（圈注也是橙色），页面 CSS 别再加别的颜色。
  - 深色底投到幕布上容易发灰：正文已经是白和很浅的青白，字描粗了一点，描边 2.5px 起；页面里正文不要用比 `--ink-2` 更暗的颜色。讲过的拍只淡到 .7。
  - 四周的图框只占最外面 16px，左右各留 120px 写就碰不到，不算禁区。页码和装配步骤的禁区是 x 1340–1856、y 20–80。
  - 卡片的零件编号压在右上角、往外探出约 22px，斜线阴影往右下错开 12px：一排卡片之间至少留 40px。截图位顶上多了一条 26px 高的尺寸标注线，同样宽的截图会比别的风格高一点。
  - 可选的图签栏：在页面里写 `<div class="bp-titleblock" data-speaker="讲者名"></div>`，右下角贴着图框出现一条（图名取这一页的主题或标题，后面是讲者、审核、装配进度），复制命令时审图章盖在「审核」格里。它约 900×56，在 y 1008 以下，那一页底部右边别放字。换到别的风格时它是空的，什么也不显示。
- **默认形象**：圈圈 `quanquan`（一只会画圈的制图圆规，白线自己就亮，引擎不再加描边）。
- **动效**：第一次打开时有开场（图框一笔描出、大标题写出、基线画出）；零件出场先描一圈浅青的安装位，零件再从一侧滑进来回弹对位，零件编号弹出，字一行行写出来；文字从左往右写出；竖排步骤之间往下画一道点划中心线；悬停时零件上出十字准线、四角亮出小方块；点击处画一个圆规圈；退一拍时零件滑回去；翻页时新的一张图纸整张推进来。
- **自带出场名**：`build`、`fit`、`scribe`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

#### 漫画 `comic`

- **样子**：米白漫画原稿纸，四周一圈淡蓝裁切线和角标；黑白墨线加朱红、钴蓝两个专色。卡片、小格、步骤、终端、截图位都是一个个分镜格：毛笔墨线格框（中间粗两头收、四角出头交叉），右下错开一块半调网点当阴影；可复制的命令是一格墨黑、朱红网点阴影；一句话解释是白底旁白框；金句像拟声大字（粗墨字、一圈留白、朱红错位影子）；重点词转朱红，下半截垫一条淡网点；「已复制！」是朱红锯齿形的爆炸气泡。节拍指示是右上角一排分镜小缩略格。
- **适合**：讲故事、前后对比、有情绪的转折、轻松的吐槽和反转。
- **不适合**：大段代码、密集数据、很正式的汇报。
- **脾气**：
  - 禁区：除了所有风格共有的主题行和右上角页码、节拍格，四边离舞台边 24px 以内是裁切线外，内容别放进去（按左右各留 120px 写就不会碰到）。
  - 配色只有墨、朱红、钴蓝：卡片颜色 `t-yellow`、`t-peach`、`t-pink` 是朱红网点阴影，`t-blue`、`t-mint` 是钴蓝网点阴影，`t-white` 和不写是墨色网点，格子本身都是白的。朱红只给重点词、圈注和金句的影子，页面 CSS 别再引入别的颜色。
  - 卡片的胶带 `tape`、图钉 `pin` 不画。格子的网点阴影往右下多占 14px，格子之间留 20px 以上的空。
  - 没有挑浏览器的效果。
- **默认形象**：叨叨 `daodao`（一个毛笔墨线的椭圆对话框，右下一块网点，朱红斜线腮红；舞台上 177×143）。
- **动效**：第一次打开时有约 1 秒的开场（裁切线浮出、格号标签弹出、右上角的页码落下、缩略格一格格弹出、大标题横切入，第 0 拍按格框 → 内容 → 大字 → 气泡出场）；格子先描出四条墨线、网点阴影浮出、里面的字弹入；金句和拟声字从很大砸下，落地闪一圈集中线；命令带着速度线横切进来；对白气泡最后「啵」地冒出；悬停时格子抬起、右上角冒三道钴蓝效果线；换拍时当前的缩略格「啪」地落定、拍号掉下来；退一拍时网点沉回、墨线倒着收掉；翻页像斜着切一刀横切进来。
- **自带出场名**：`frame`、`boing`、`bam`、`bubble`、`dash`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。
- **可选组件**（只有漫画认，换风格后只剩普通的字和块）：`.cm-panel` 分镜格（和卡片一样的格子，里面的东西可以伸出格子破格，比如 `<div class="cm-panel abs" style="…"><p class="cm-sfx abs" style="left:520px;top:-56px">到顶啦！</p></div>`）；`.cm-say` 对白气泡（加 `.tail-r` 尾巴换到右下）；`.cm-sfx` 拟声大字（默认歪 -6°，加 `.cool` 换成钴蓝）。对白要短、字要大。

### 现代风

#### 科技暗黑 `dark`

- **样子**：像产品发布会的暗色质感。近黑底加唯一的冷色冰蓝，背景有极淡的噪点和柔和光晕；卡片是深色缎面配 1px 渐变描边，银色渐变大标题；字用系统黑体（不是楷书），命令用等宽字。重点词被一道白光扫过、染成冰蓝；当前这一拍的组件描边会染成冰蓝。节拍指示是玻璃胶囊。
- **适合**：技术分享、命令行教学、发布会、产品介绍。
- **不适合**：温情人文、大段阅读、需要很多插图的内容。
- **脾气**：
  - 只有一个冷色：卡片颜色 `t-*` 在这里都是冰蓝或浅灰，靠颜色区分不了几张卡片，用标题和位置区分。
  - 深色底投到幕布上容易发灰，正文已经提亮到接近白；页面 CSS 里正文不要用比 `--ink-2` 更暗的颜色，线和字要亮、要粗一点。
  - 不要加发光线、HUD 角标、乱码这类显廉价的装饰。
  - 字体是黑体，同样的字比楷书略宽：从手绘风换过来时，原来刚好放下的字可能溢出，换完一定重跑自检。
  - 渐变描边在不支持的浏览器里退回普通描边，不影响内容。
  - 页码和节拍胶囊的禁区是 x 1340–1856、y 14–82。
- **默认形象**：微光 `weiguang`（悬浮的钛灰小方块机器人，一条冰蓝眼灯；自带亮边，引擎不再加描边）。
- **动效**：第一次打开时有开场（光晕亮起、主题行落下、大标题由虚到实）；文字默认「由虚到实」浮上来，卡片类组件浮起并有一道光沿描边扫过，命令柔边擦出；退一拍时字先虚化、组件再沉下去；翻页时旧页上收淡出、新页从下面浮上来。
- **自带出场名**：`focus`、`lift`、`wipe`、`sweep`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

#### 毛玻璃 `frost`

- **样子**：淡薰衣草底上四团静止的彩色光斑（紫、粉、蓝、杏）和两颗小球；卡片、小格、步骤、截图位是薄的乳白磨砂玻璃（半透明白底、细亮白边、背后重模糊）；终端和可复制的命令是深靛色玻璃胶囊。重点词是一枚玻璃小胶囊，字从墨色刷成紫到品红的渐变。字用系统黑体，命令用等宽字。节拍指示是右上角的磨砂胶囊。
- **适合**：产品介绍、工具上手、新功能发布。
- **不适合**：大段文字、表格和代码、严肃学术。
- **脾气**：
  - 配色只有底色、深靛墨，和紫到品红一种强调色；卡片颜色 `t-*` 只是左上角透出一团柔色（`t-yellow`、`t-peach` 是杏色，`t-mint` 是紫，`t-pink` 粉，`t-blue` 蓝），靠颜色区分不了太多卡片。
  - 磨砂（backdrop-filter）不支持的浏览器退成 84% 白底卡片，不影响阅读；一页上磨砂卡片很多时，配置差的电脑翻拍可能有点卡。
  - 页面 CSS 别给装着卡片的外层写半透明（opacity 小于 1）：外层一旦半透明，里面卡片的磨砂就失效。讲过的拍变淡风格已经处理好了。
  - 背景左边 x 120 以内、右边 x 1780 以外各有一颗小球，内容按左右各留 120px 写就不会碰到。
  - 字体是黑体，同样的字比楷书略宽：从手绘风换过来后一定重跑自检。
  - 页码和节拍胶囊的禁区是 x 1340–1856、y 14–82。
- **默认形象**：小雾 `xiaowu`（一块磨砂玻璃小果冻，里面透出彩色反光；自带白色亮边）。
- **动效**：第一次打开有约 1 秒的开场（光斑亮起、小球弹出、标题由虚到实）；文字默认从雾里凝出，卡片类组件从雾里浮上来、一道光掠过玻璃；悬停时卡片浮起、柔光跟着鼠标；复制时冒出一串磨砂小泡泡；退一拍时字先化回雾里、玻璃再沉下去；翻页时旧页上收、新页从下面浮上来。
- **自带出场名**：`mist`、`float`、`sheen`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

#### 液态玻璃 `glass`

- **样子**：柔和静止的彩色光斑底（薄荷水色、长春花蓝、杏色、一抹淡紫，加两颗光亮的小球）；卡片、步骤、小格、终端、截图位都是透明而厚的玻璃，边缘把背后的光斑折弯，大圆角，竖排的步骤是一块块胶囊。字用系统黑体，命令用等宽字；强调色只有一个海蓝。重点词被一枚小玻璃胶囊包住；节拍指示是玻璃胶囊，当前那颗点上停着一颗放大镜似的小液滴。和毛玻璃的区别：毛玻璃是薄的磨砂白卡片、很模糊；液态玻璃几乎不模糊，靠边缘折光和厚度。
- **适合**：产品、界面、设计、科技类，每页信息不多。
- **不适合**：长文字、大表格、元素很密的页。
- **脾气**：
  - 只有一个海蓝：卡片颜色 `t-*` 在这里只是玻璃上很淡的底色（杏、薄荷、长春花蓝、淡紫），靠颜色区分不了几张卡片，用标题和位置区分。
  - 折射只有 Chrome 和 Edge 支持，其他浏览器退成轻模糊加边缘光（地址加 `?flat` 能看退化后的样子）；配置差的电脑上前两次出场量到掉帧，会自动关掉折射。
  - 每页的玻璃块别太多（一般 3–6 块）：每块都要实时折射，多了会卡、也乱。
  - 页面 CSS 别给装着玻璃的外层写半透明：外层半透明时里面的玻璃没有折射（讲过变淡、翻页淡入淡出时会暂时这样，属于正常）。
  - 背景右中部（约 x 1250–1410、y 310–480）和左下角各有一颗光亮的小球，字压在上面照样看得清，但封面、结尾的大字金句最好别正好压在右边那颗上。
  - 浅色底，投影上可读性好；玻璃本身很淡，对比度低的投影仪上玻璃边可能看不清，信息要靠字，别靠框。
  - 字体是黑体，比楷书略宽，从手绘风换过来后一定重跑自检。
  - 页码和节拍胶囊的禁区是 x 1340–1856、y 14–82。
- **默认形象**：透透 `toutou`（一颗透亮的玻璃小液滴，动起来像果冻）。
- **动效**：第一次打开时有开场（光斑淡入、主题行和节拍胶囊像水珠一样弹开、大标题浮上来）；玻璃组件从一颗液滴流开、果冻回弹，字从左滑进来；文字浮上来；命令和标签果冻弹出；退一拍时玻璃收回成液滴消失；翻页时旧页上收淡出、新页从下面浮上来。
- **自带出场名**：`pour`、`float`、`jelly`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

#### 扁平插画 `flat`

- **样子**：像产品官网的几何扁平插画。暖白底、墨蓝字，强调色只有珊瑚和明黄，加上墨蓝一共三组颜色。全页统一左上受光：卡片、小格、终端、截图位、命令都是圆角色面，右下露出一条深一级的厚度、左上一道亮边、投影落向右下（不模糊）。步骤的序号是珊瑚、明黄、墨蓝轮换的圆片，横排时每步垫一块浅色色面；命令是墨蓝胶囊，标签和「已复制」是明黄贴纸，截图位是一扇网页窗口。重点词底下弹出一块明黄色块、右上角迸出三道珊瑚短线。字用系统黑体（粗），命令用等宽字。节拍指示是白色胶囊里的一排进度条。
- **适合**：上手教程、产品介绍、流程步骤、新人或非技术听众。
- **不适合**：大段代码、数据图表、严肃汇报。
- **脾气**：
  - 只有三组颜色：卡片颜色 `t-yellow` 是明黄，`t-pink`、`t-peach` 是珊瑚，`t-blue`、`t-mint` 是墨蓝浅调，`t-white` 和不写是白色。页面 CSS 别再引入别的颜色。
  - 光从左上来：页面 CSS 自己加阴影时一律落向右下、不模糊（比如 `8px 10px 0 rgba(31,42,68,.1)`），别加柔和的模糊阴影。
  - 风格只给通用组件画光影，不带样页那种每页专用的插画；想要插画得自己画，长稿成本高。
  - 字体是黑体（粗），比楷书略宽：从手绘风换过来后一定重跑自检。
  - 讲过的拍淡到 0.58，墨蓝的终端和命令淡下去会偏灰，属于正常。
  - 没有滤镜和模糊，最省性能，没有挑浏览器的效果。
  - 页码和节拍胶囊的禁区是 x 1340–1856、y 12–84。左右页边各有一件漂浮的小几何（背景，不算禁区），按左右各留 120px 写就碰不到。
- **默认形象**：小页 `xiaoye`（围黄围巾的几何小狐狸；朝左时自己画镜像，仍然左上受光；深色底上引擎会给它加浅色描边）。
- **动效**：第一次打开时有约 1 秒的开场（背景大圆弹开、标题逐字弹起）；文字默认从下面弹上来，卡片类组件从一颗胶囊展开成色面、里面的字依次弹起，步骤序号转着弹出，命令和标签像贴纸一样弹出；悬停时组件朝左上抬起、投影变长；复制成功时明黄贴纸歪着拍上来、迸出几何纸屑；退一拍时色面缩一下、序号收回；翻页时旧页滑走、新页带一点回弹滑进来。
- **自带出场名**：`spring`、`unfold`、`chars`、`slap`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

#### 杂志复古 `magazine`

- **样子**：撞色拼贴的老杂志。米白纸底带极淡纸纹，墨绿、橘红两个撞色，宋体大标题，页眉下面一粗一细两道栏线。卡片、步骤、截图位是用牛皮纸胶带贴上去的纸条；步骤的大序号（01、02…）背后有一层没套准的橘红；重点词是剪下来的橘红纸条贴在字底下、字反白；命令是一张剪角券，复制时剪刀沿虚线剪过去，贴上一张橘红「已复制」小标签。节拍指示是几小片纸。
- **适合**：观点、方法论、读书分享、复盘总结。
- **不适合**：大量代码、密集图表、热闹的场合。
- **脾气**：
  - 配色只有米白、墨绿、橘红，加墨黑字和纸白。卡片颜色 `t-*` 在这里是纸白、旧报纸米色，以及墨绿、橘红各一档很浅的纸，别再加别的颜色。橘红留给重点词、圈注和当前拍。
  - 页码和节拍纸片挪到右边和栏线对齐，禁区是 x 1390–1810、y 22–74；页眉栏线 x 120–1800、y 79–92 也是禁区（大标题在它下面，不碰）。
  - 纸条歪多少、左右怎么错开由页面决定：卡片、截图写 `--r`，步骤的一项要加 `class="tilt"` 再写 `--r`。
  - 可选的封面色块：`<div class="mag-cover abs" style="left:…;top:…;width:…;height:…">…</div>`，是一大块撕边墨绿纸，压着一枚橘红网点圆，放在里面的字自动变成米白；加 `left` 撕边换到左边，加 `no-disc` 不要网点圆。要写在页面 html 的最前面；网点圆会从色块边上探出约 170px，别让它压到旁边的字。换到别的风格时它只是一个透明的容器。样板页不带它（样板页要在所有风格下通用）。
  - 字体是宋体，和现代风别的风格（黑体）不一样：从手绘风换过来后要重跑自检；和别的现代风风格按章混用时，标题字体会跟着章变。系统里只有 Windows 自带的细宋体时，宋体字会自动描边加粗。
  - 很老的浏览器里重点词的字不反白（墨色字压在橘红纸条上），不影响阅读。
- **默认形象**：小铅 `xiaoqian`（一枚会走路的橘红铅字块，头顶翘着一个反写的 ¶；自带米白剪纸边，深色底上也不用加描边）。
- **动效**：第一次打开有约 1.3 秒的开场（栏线拉开、主题行落下、封面色块贴上、网点圆滚进来、大标题排上来）。文字默认「排字」：从自己的底边升上来。纸条类组件「贴上」：带着影子落下、胶带按上、里面的字一行行排上来，序号的套印从偏位处对过来。退一拍时纸条往上揭起拿走；翻页时新页从一边揭开。
- **自带出场名**：`paste`、`typeset`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

#### 新粗野主义 `brutal`

- **样子**：奶黄底上一层很淡的墨点阵；字、粗黑描边、无模糊的硬阴影都是同一种墨黑；强调色只有黄、粉、蓝三种高饱和色块。卡片是白面板、顶上一条色带（有 `.lab` 时色带里写小标签），横排步骤上沿压一枚「STEP 01」色块贴纸；重点词是一块带描边和硬阴影的贴纸色块；命令是一颗能按下去的大按钮，「已复制」是一枚黄贴纸。字用系统黑体（粗），命令用等宽字。节拍指示是一枚带硬阴影的小按钮，每拍一个方格。
- **适合**：上手教程、流程步骤、产品和工具介绍、内部分享。
- **不适合**：严肃汇报、对外的正式场合、大段文字。
- **脾气**：
  - 只有黄、粉、蓝三种强调色：`t-yellow`、`t-pink`、`t-blue` 是卡片色带的颜色，`t-mint` 归到蓝、`t-peach` 归到粉、`t-white` 是白色带。页面 CSS 别再引入别的颜色；重点词贴纸自动取所在卡片的颜色。
  - 每个组件都带 4px 描边和 8px 硬阴影，本身就很「重」：一页别放太多卡片和小格，组件之间至少留 30px，右下角给阴影留出 8px。
  - 带 `.lab` 的卡片，小标签变成卡片顶上的色带，卡片比别的风格高出约 60px，下面要留空。横排步骤的「STEP 01」贴纸往上伸出 22px，步骤上面别贴着放字。
  - 字体是粗黑体，同样的字比楷书宽：从手绘风换过来时，换完一定重跑自检。
  - 没有挑浏览器的效果；墨黑对奶黄，投到幕布上可读性好。
  - 页码和节拍按钮的禁区是 x 1320–1870、y 12–90。
- **默认形象**：砰砰 `pengpeng`（长了手脚的黄色爆炸贴纸小怪物，粗黑描边；风格给它加一道墨色硬投影）。
- **动效**：第一次打开时有约 1 秒的开场（主题行的章节块砸下、标题一个字一个字砸下来、节拍按钮盖下）；卡片、小格、步骤、终端、截图、命令从上面「砸」下来，落地压进阴影再弹回、两侧甩出冲击线，已经落定的卡片被震一下；标签啪地拍上，正文弹起；悬停时组件离阴影远一点、朝鼠标那侧歪一点，按下压进阴影；复制时按钮按到底闪黄、贴上「已复制」；退一拍时卡片被捏起来往上抛走；翻页时旧页被一把推开、新页冲进来。
- **自带出场名**：`slam`、`smash`、`slap`、`snap`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

### 企业风

#### 方果 `fangguo`

- **样子**：方果 ERP 的品牌风格，学方果官网「工具箱」那组图：高级、干净、大气。近白底上一层很淡、会慢慢动的背景，按页型自动换两组：封面、章节页、结尾、关于我们是「柔光 + 波纹」（三团很浅的蓝、淡紫、薄荷柔光慢慢游移，底部四条细波浪向左流淌），内容页、数据页是「晕染 + 网格」（两团淡蓝光晕呼吸，1px 极淡网格，一团柔光沿网格游走）。卡片是纯白大圆角、极淡投影；主色品牌蓝 #3B74F0，品牌红 #ED5E6E 只点题。数字用 Bahnschrift（退到 DIN Alternate）字重 600、等宽数字，数字和单位分开排（单位 0.36 倍、颜色淡），可以带淡蓝渐变。主题行最前面是方果 Logo 加一道细竖线，节拍指示是右上角一排小圆点，当前拍拉成品牌蓝短条。字用系统黑体，命令用等宽字。
- **适合**：给客户演讲、领导汇报、产品介绍、经营数据。
- **不适合**：手绘感、童趣的内容，大段代码；和方果无关的场合（每页都带方果 Logo）。
- **脾气**：
  - 品牌红只点题：一页最多一处 `<span class="fg-red">`（封面标题里的一两个字），其余强调都用品牌蓝。卡片颜色 `t-*` 是很浅的一层底色（蓝、青、珊瑚、琥珀），白色最常用。
  - 背景按页型自动换：页面里有 `.fg-cover`、`.fg-chapter`、`.fg-about`，或者 `noTitle: true` 的页用「柔光 + 波纹」，其余用「晕染 + 网格」；要改就在页面 html 里放 `<i data-fg-bg="a" hidden></i>`（或 `"b"`）。背景只动位移和遮罩，20–100 秒一圈；系统开了「减少动态效果」、自检、截图时都停住。
  - 出血底板：页面里写 `<i class="fg-bleed" hidden></i>`（加 `fg-left` 换到左边），右边一整块浅蓝底板从舞台 x 1000 铺到窗口边缘、上下出血，窗口不是 16:9 也铺满；底板上的字照样清楚。
  - 课件里带一份品牌素材（`vendor/brand/fangguo/`：Logo 两张、公众号、抖音、商务合作企业微信三张二维码，约 90KB），`new` 选了 fangguo 时自动带上，风格 CSS 用相对路径引用，双击离线打开也显示。搭好骨架后再换成方果（第 6 节），第 b 步还要把 `〈本 skill 目录〉/template/vendor/brand/fangguo/` 整个复制到 `〈课件目录〉/vendor/brand/fangguo/`，不然 Logo 和二维码不显示。
  - 数字字体 Bahnschrift 是 Windows 自带的，苹果上用 DIN Alternate，都没有时退成系统字体（数字会略宽）。
  - 浅色底，投到幕布上也看得清。
  - 字体是黑体，比楷书略宽：从手绘风换过来后一定重跑自检。
  - 页码和节拍点挪到 right 120、top 18，和主题行同一条中线，禁区是 x 1400–1820、y 14–82。
- **默认形象**：方方 `fangfang`（方果 Logo 化来的红色圆角方块小果子，头顶 T 形果柄和一片叶子）。除了 `idle`、`point`、`happy`、`rest`，还有 `ask` 疑问、`think` 思考、`idea` 灵感、`wow` 惊讶、`ok` 点赞、`thanks` 致谢，写在 `data-mascot-pose` 里（讲「为什么」用 `ask`，讲关键数字用 `wow`，结尾用 `thanks`）。
- **动效**：克制。第一次打开有约 1 秒的开场（背景淡入，主题行、大标题、第 0 拍依次淡入上浮）；每拍 0.3–0.5 秒、平滑缓动，不弹跳、不砸、不过冲：内容淡入上浮，数字从 0 滚到读数，柱子和环按拍生长，趋势线从左往右画出来，当前一步用品牌蓝点亮；重点词变成品牌蓝、底下铺开一道淡蓝（不放大）；翻页时旧页上收淡出、新页从下面浮上来。
- **自带出场名**：`fgrise`、`fgfade`、`fgmock`、`fghub`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。
- **专用组件**（类名 `fg-` 开头，只在方果里有样子；样板页 `samples/fangguo.js` 每个都用了一遍，完整说明在 `scenes/fangguo.js` 开头）。图表都是「填数字就能用」：
  - 大数字：`<b class="fg-num fg-g" data-to="52" style="font-size:96px">52<small>万单</small></b>`。单位写在 `<small>`；`fg-g` 是淡蓝渐变；写了 `data-to` 到拍时从 0 滚到读数（小数位数照 `data-to`，原字带千分位逗号就带逗号）。
  - 柱状图：`<div class="fg-bars" data-fg-bars="286,318,352,371,402,511" data-fg-labels="4 月,5 月,6 月,7 月,8 月,9 月" data-fg-hi="6" data-fg-hi-beat="2" style="height:400px"></div>`。`data-fg-hi` 是第几根用渐变蓝突出，`data-fg-hi-beat`（可选）是到第几拍才点亮，`data-fg-max`（可选）是纵轴上限；读数和月份是真的字。
  - 环形图：`<div class="fg-donut" data-fg-donut="52,27,21"><b class="fg-num" data-to="1284">1,284</b><span data-small>Q3 合计</span></div>`，中间放合计；旁边的图例 `<div class="fg-legend"><p><i></i>跨境平台<b>52%</b></p>…</div>` 色块按顺序自动对上（`data-fg-colors` 可以换颜色）。
  - 趋势线：`<div class="fg-line" data-fg-line="31,32,34,…,52" data-fg-labels="4 月,,,6 月,,,8 月,,,9 月" style="height:220px"></div>`，横轴标签空的不写；终点一个圆点和读数（`data-fg-end` 可以改）。
  - 进度环：`<div class="fg-ring" data-fg-ring="90" data-fg-tone="teal"><b class="fg-num" data-to="90">90<small>%</small></b></div>`。
- **招牌交互**（只有方果有，讲 SaaS 产品和 POD 工厂最贴切；每拍 0.3–0.8 秒、平滑，同一页一次只动一处主角，减少动态和自检时直接到位）：
  - 界面演示：窗口加 `fg-demo`，`<div class="fg-win fg-demo">…<span class="fg-key" data-fg-click="1">一键拉单</span>…<div class="fg-demo-row" data-beat="1"><i class="fg-chk"></i><b>订单号</b><span>商品</span><em>已拉取</em></div>…<span class="fg-toast" data-beat="3">订单已全部到齐</span></div>`。写了 `data-fg-click="拍号"` 的元素，到那一拍光标移过去点一下；列表一行行出现、行首打勾；右上角的提示 `.fg-toast` 留在版面上不消失。
  - 套图：印花 `<i class="fg-print" style="width:360px;height:360px"></i>`，商品 `<div class="fg-prod" data-fg-prod="tee" data-beat="1"><span>T 恤</span></div>`（`tee` T 恤、`hoodie` 卫衣、`case` 手机壳、`bag` 帆布包、`mug` 马克杯、`pillow` 抱枕，轮廓是 SVG）。到拍时印花飞到商品的印花位置上落下。
  - 订单流水线：`<div class="fg-pipe"><div class="fg-st"><i class="fg-ico" data-fg-ico="cart"></i><b>接单</b><p data-beat="1"><b class="fg-num" data-to="2318">2,318</b>今日订单</p></div>…</div>`。工位第 0 拍就摆好（灰），讲到哪一站，那一站亮起、计数滚上来，一张订单卡沿轨道走过去（最多 6 站）。
  - 平台汇聚：`<div class="fg-hub" style="width:980px;height:720px"><b class="fg-plt" data-beat="1">TEMU</b>…</div>`。平台胶囊从正上方顺时针排成一圈，中间是方果；胶囊亮起时一条线画向中间、一颗光点沿线流过去（只流一趟）。`data-fg-rx`、`data-fg-ry` 调圈的大小。
  - 聚焦框：在 `.fg-win`（或 `.fg-lensbox`）里给要框的元素写 `data-fg-focus="拍号"`，到那一拍框移过去，四周压暗一点（字仍看得清）。说明写在框外面，一拍一句，讲完留着。
  - 按位滚动的数字：`<b class="fg-num fg-odo">2,318</b>`，到拍时每一位先快速翻动、再从左到右依次停在读数上（只改这个数字自己的字，不用写 `data-to`；逗号、小数点、单位不动）。
  - 新旧对比：`<p class="fg-vs"><s class="fg-old">20 分钟</s><i class="fg-arrow"></i><b class="fg-num fg-new" data-beat="1">10<small>秒</small></b></p>`，新数字到拍时旧的划一道红线（仍读得清）。新数字也可以写在 `.fg-vs` 后面。
- **配图和文字为主的页**（没有数字时用）：
  - 截图叠放：`<div class="fg-stack" style="width;height"><figure class="shot" data-beat="1" data-src="素材/a.png" data-caption="上架工具" style="left;top;width;--ar:512/375;--fit:contain;--r:-1.5deg"></figure>…</div>`。几张截图错落叠在一起，可以轻微倾斜（`--r` 不超过 2°），一拍出一张，当前讲的那张浮到最上面、放大一点、外面一圈品牌蓝。截图之间只叠图、别叠住别的截图的图注。
  - 图文拼贴：`<div class="fg-collage" style="width;height"><figure class="shot" …></figure>…</div>`。第一张是主图（投影更深），其余叠在边上；同一张横幅照片可以用不同的 `--pos` 裁出几块（点开大图时看到的是整张原图）。
  - 价值观网格：`<div class="fg-values"><div class="fg-val"><i></i><b>长期主义</b><p data-beat="1">长期价值和短期利益，选长期</p></div>…</div>`。编辑式排版、不做卡片：自动编号、大字关键词、一句小字说明，中间一栏往下错开；关键词第 0 拍就在，说明到拍出现，顶上的细线铺成品牌蓝，当前一拍的关键词变蓝。一行三条（`--cols` 可改），说明 14 个字以内。
  - 叠放、拼贴里的截图，「点开看大图」的角标平时藏起来，鼠标移上去才出现，照样点一下就能看大图。
- **讲软件、讲操作时用的小件**：
  - 对话：`<div class="fg-win"><div class="fg-win-hd">…</div><div class="fg-chat"><p class="fg-msg me" data-beat="1">你说的话</p><p class="fg-msg ai" data-beat="2">AI 的回复</p></div></div>`。你说的靠右、品牌蓝底；AI 说的靠左、浅灰底、前面一个「AI」小标签；一拍一条，讲过的留着。AI 消息里可以放 `<p class="fg-opts"><span>1 先过一遍</span><span>2 先不学</span></p>`（编号选项）；写了 `data-copy` 的消息点一下就复制。
  - 代码条：`<span class="fg-code" data-copy="要复制的字">node -v</span>`，行内的一小段命令或网址，等宽字、浅蓝底。
  - 按键：`<i class="fg-kbd">S</i>`，一枚白色键帽，讲快捷键时用。
  - 平台汇聚中间不放方果 Logo 时，在 `.fg-hub` 上写 `data-fg-core="几个字"`。
- **版式工具**：出血底板 `<i class="fg-bleed" hidden></i>` 有四种——默认右边一块浅蓝、`fg-left` 左边、`fg-slant` 右边一块斜切的浅蓝、`fg-wash` 整屏一层淡蓝晕染（金句页用）；金句 `<p class="fg-quote">…<span class="fg-hl">词</span>…</p>`（112px 深墨色大字，上面一道品牌蓝渐变短线，关键词是品牌蓝渐变，一页一句）；一组淡蓝同心细圆环装饰 `<i class="fg-deco"></i>`（不放字）。
  - 指标卡 `.fg-kpi`、渐变圆角图标 `.fg-ico[data-fg-ico="box"]`（`data-fg-tone`：blue、teal、coral、purple、amber、red）、白色界面窗 `.fg-win`（加 `fg-float` 是倾斜 2° 的浮窗）、折角标签 `.fg-fold`、小胶囊 `.fg-chip`、横小卡 `.fg-mini`、功能卡 `.fg-feats > .fg-fc`、平台横栏 `.fg-plat`、流程清单 `.fg-flow > .fg-step`（当前一步点亮）、封面 `.fg-cover`、章节页 `.fg-chapter` 加 `.fg-bigno`、关于我们 `.fg-about` 加二维码卡 `.fg-qr[data-fg-qr="wechat|douyin|business"]` 和联系方式 `.fg-contact`。

### 像素风

#### 像素游戏 `pixel`

- **样子**：一块 8-bit 游戏的标题画面。深夜蓝的抖动渐变夜空、几颗像素星星、两层像素远山；所有东西对齐同一张 4px 网格，只用 16 色。字是中文像素字体（缝合像素字体）；大标题是金色抖动字面配深色字板和锈红厚度；卡片是 RPG 窗口（暖白像素框、四角切一格、右下硬阴影）；重点词是金色加一格像素下划线；节拍指示是经验条；可复制的命令是一颗像素按钮。
- **适合**：上手教程、新人引导、闯关式分步、轻松的团队分享。
- **不适合**：严肃汇报、财务数据、文字很密的页。
- **脾气**：
  - 字大：正文、卡片标题、命令、标签都是 48px（一个字点占 4px 一格），大标题和金句 96px；主题行、页码、小格编号、图注、「已复制」、形象气泡是 24px。大标题 15 个字以内，长了会换行压到一句话解释。一句话解释在 y 220，30 字以内。内容从 y 290 左右开始。卡片宽 W 时一行约 (W−80)÷48 个字。命令一个英文字符约 24px，一行 60 个字符以内。从别的风格换过来一定重跑自检。
  - 页面里自己写字号时尽量用 12 的倍数（24、48、96）：像素字体是 12px 点阵，别的字号点会大小不匀。
  - 只有 16 色。卡片颜色 `t-*` 只换窗框颜色，窗口本身都是深蓝。页面 CSS 别再引入别的颜色、渐变、圆角。
  - 自成一家：字体、网格自成一套，不和手绘风、现代风混用。
  - 课件里带一份缝合像素字体（`vendor/fonts/pixel/`，约 679KB，OFL 许可），`new` 选了 pixel 时自动带上。搭好骨架后再换成像素游戏（第 6 节），第 b 步还要把 `〈本 skill 目录〉/template/vendor/fonts/pixel/` 整个复制到 `〈课件目录〉/vendor/fonts/pixel/`，不然字会退回系统黑体、变宽、可能溢出。
  - 深色底投到幕布上容易发灰：正文已经用暖白，每段字带一格深色硬投影。
  - 窗口缩放不是整数倍时，像素会被重新采样，不再绝对锐利。舞台缩得很小（很小的窗口、手机竖屏阅读模式）时，线稿和圈注退回普通直线。
  - 页码和经验条的禁区是 x 1300–1872、y 12–84。
- **默认形象**：小旗 `xiaoqi`（戴毛线帽、背三角旗的像素小向导；浅紫亮边画在像素里，引擎不再加描边）。
- **动效**：第一次打开时有约 1 秒的开场（星星分三步亮起、远山逐格升起、大标题一个字一个字掉下来落位、角上一闪，第 0 拍逐字打出）。所有出场都逐格走、不做半透明的平滑过渡：卡片类组件像 RPG 窗口先横向拉开、再竖向展开，字逐字打出；金句掉下来、标签蹦出来；重点词反白闪两下后落定；进一拍时经验条灌满一格；复制时命令按钮顶出一枚旋转的像素金币；退一拍时窗口压扁收没；翻页时新页逐格从一边擦出来。
- **自带出场名**：`pxwin`、`pxtype`、`pxdrop`、`pxpop`、`pxtitle`。只在这种风格里认，页面里别写（换风格会报提醒），风格会自己默认用。

## 4. 按章分配风格

内容跨度大时（比如前面讲愿景、中间讲安装命令、后面讲故事），可以按章用不同的风格。规矩：

- **最多 3 种。** 多了像拼凑，讲者和观众都累。
- **只在同一类里混。** 手绘风的 8 种可以互相搭，现代风的 6 种也可以互相搭；像素风只有像素游戏一种，只能单独用。跨类混用，`check` 和自检都会报「风格混用了不同的类」。
- **全稿统一的东西不变**：字体、强调色的用法、重点词的标法、节拍指示的位置、形象。一份课件只用一个形象，按章换风格时形象不跟着换。现代风里杂志复古是宋体、其余是黑体：它和别的现代风风格混用时标题字体会跟着章变，想全稿字体一致就让它单独用。
- **同一章只用一种风格**，别在一章里来回换。

两个例子：手绘风，开场和收尾用方格纸，讲安装命令的那章用黑板，讲上手流程的那章用水彩田园；现代风，产品介绍用毛玻璃，讲命令行的那章用科技暗黑。

写法：

1. 确认风格时一次记下全部，第一种是主风格（形象跟着它走）：`confirm <课件目录> style --scenes paper,board,watercolor`。
2. 搭骨架时 `new` 照这个列表把几种风格都放进课件（`guide` 会给出完整命令）。
3. 每页的 `scene` 写这一章的风格：方格纸那几章写 `scene: 'paper'`，黑板那章写 `scene: 'board'`。

## 5. 临时看看别的风格

- 在浏览器地址栏 `index.html` 后面加 `?scene=键名`，整份课件临时全换成这种风格，不改任何文件。**只认这份课件里已经引入的风格**（`new` 只放进了选中的几种），没引入的会被忽略、照原样显示。
- 想看没引入的风格是什么样，用样册：`styles --open`。
- 用户看完 3 页试做想换风格，先打开样册比较，定了再照下一节真的换。

## 6. 搭好骨架后换风格

`new` 已经把选中的风格复制进了课件，`index.html` 里也写好了引入。之后用户要换风格，照下面 a–e 做。**这是唯一允许改 `index.html` 章节区以外的情况**，而且只改引入风格的那两行；平时写页面一律只改 `slides/` 和章节区。

下面的〈新风格〉〈旧风格〉换成键名（比如 board、paper），〈本 skill 目录〉是 SKILL.md 所在的目录，〈课件目录〉是这份课件的目录；`guide` 在 ④ 风格（已经搭好骨架时）和 ⑥ 先做 3 页（给用户看 3 页的时候）会给出填好路径的同一套命令，能直接复制。

a. 记下新风格（形象先不换，`--mascot` 后面写现在用的形象）：

```
node "〈本 skill 目录〉/scripts/li-talk.mjs" confirm "〈课件目录〉" style --scenes 〈新风格〉 --mascot 〈现在的形象〉
```

b. 把 `〈本 skill 目录〉/template/scenes/〈新风格〉.js` 和 `〈新风格〉.css` 复制到 `〈课件目录〉/scenes/`。换成像素游戏 `pixel` 时，还要把 `〈本 skill 目录〉/template/vendor/fonts/pixel/` 整个复制到 `〈课件目录〉/vendor/fonts/pixel/`（风格自带的字体），不然字会退回系统黑体。换成方果 `fangguo` 时，还要把 `〈本 skill 目录〉/template/vendor/brand/fangguo/` 整个复制到 `〈课件目录〉/vendor/brand/fangguo/`（Logo 和二维码），不然它们不显示。

c. 把 `〈课件目录〉/index.html` 里 `scenes/〈旧风格〉.css`、`scenes/〈旧风格〉.js` 这两行的文件名换成新风格（只有换风格时才动章节区以外的这两行）。改完是这样：

```html
<link rel="stylesheet" href="scenes/〈新风格〉.css">
…
<script src="scenes/〈新风格〉.js"></script>
```

旧风格的两个文件留在 `scenes/` 里也没关系：`index.html` 不引入就不会加载。

d. 把 `〈课件目录〉/slides/` 里每页的 `scene: '〈旧风格〉'` 换成新风格。页面用了旧风格的专用组件（类名带旧风格前缀，比如 `.ink-*`、`.px-*`，是照旧风格自己的样板页写的）时，只改 `scene` 不够：这些组件到了新风格里会退成普通的字和块。这几页要照新风格自己的样板页（`〈本 skill 目录〉/template/samples/〈新风格〉.js`）重写版式，字和讲词照旧，先告诉用户要重写几页。

e. 重跑后台自检，错误改到 0 个：

```
node "〈本 skill 目录〉/scripts/li-talk.mjs" check "〈课件目录〉" --browser
```

换风格后常见的变化：现代风是黑体（杂志复古是宋体），字比楷书宽，可能溢出；像素手账的标题大一号；黑板底部有粉笔槽、颜色只剩白黄；蓝图的零件带编号和斜线阴影，一排卡片要多留空；新粗野主义每个组件带粗描边和硬阴影，带小标签的卡片高出一截；像素游戏字最大（正文 48px），一页放的字要少。所以第 e 步一定要做，报什么改什么。

补充两种情况（同样属于换风格，同样只动风格、形象的引入行）：

- **在原来的风格之外再加一种**（按章分配，只在同一类里加）：a 写上全部风格（`--scenes 旧风格,新风格`）；b 照做；c 改成在原来那两行下面各加一行新风格，原来的两行保留；d 只改要换的那几章。
- **用户也想换形象**（比如换成科技暗黑后想用微光）：把 `〈本 skill 目录〉/template/mascots/〈新形象〉.js` 复制到 `〈课件目录〉/mascots/`；`index.html` 里 `<script src="mascots/〈旧形象〉.js">` 这一行换成新形象，`<meta name="li-talk-mascot" content="〈旧形象〉">` 的 content 也换成新形象；第 a 步的 `--mascot` 写新形象。这一版有 16 个形象：尖尖 `jianjian`、沙沙 `shasha`、点点 `diandian`、卷卷 `juanjuan`、朵朵 `duoduo`、墨丸 `mowan`、圈圈 `quanquan`、叨叨 `daodao`、微光 `weiguang`、小雾 `xiaowu`、透透 `toutou`、小页 `xiaoye`、小铅 `xiaoqian`、砰砰 `pengpeng`、小旗 `xiaoqi`、方方 `fangfang`；`styles` 列出每种风格默认用哪个。
