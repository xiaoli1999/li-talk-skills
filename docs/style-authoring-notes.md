# 写新风格的坑

给以后写新风格（和新形象）的开发者看。这些是移植 9 种风格（毛玻璃、液态玻璃、扁平插画、杂志复古、新粗野主义、水墨国风、像素游戏，第二批的蓝图、漫画）时实际踩到的问题，按主题分组；括号里是踩过的风格。风格接口、必须实现的清单和动效硬规矩见 `design.md` 第 6.2 节，这里只记容易出错的地方。这份文档不放进 skill。

标了「引擎」的条目是引擎现在的限制，风格只能绕开；以后改了引擎，这里跟着删。

---

## 1. CSS 变量

- **`--r` 是角度。** `engine.css` 用 `@property --r { syntax: "<angle>" }` 注册了 `--r`（卡片、截图等的倾斜角）。风格里别拿 `--r` 当长度或别的用途，写了也不生效，还会让倾斜全部失灵。要别的变量就起带风格前缀的名字，比如 `--fr-blur`。（frost）
- **`--recede` 别写在 CSS 里。** 讲过的拍变到多淡由风格对象的 `recede` 字段决定，引擎写进去；CSS 里再写会被覆盖或打架。`recede` 不低于 .75（15 种风格都是 .8），低了引擎提醒并按 .75。
- **讲过变淡时，彩色块上的白字最先看不清。** 变淡是整块一起淡：色块淡向底色、白字也淡，对比度掉得比深字压浅底快得多。白字压彩色块（重点词高亮、彩色小标签）在 `.past` 里换深一档的颜色，淡下来后看着还是原来的颜色。（magazine、flat）
- **深色块放在浅底上（终端窗口），变淡后块本身发灰。** 里面的暗色字（`.dim`）要比全亮时需要的再亮一档。（flat、brutal）
- **`--idle` 这类「弱化」颜色也要过 3:1。** 空闲格、对比页「以前」那一侧是故意弱化的，但字还是要读得清。（flat、comic、ink、magazine）
- **GSAP 补间 CSS 变量要用 `fromTo`。** 变量没写在行内时，GSAP 读不到起点，会直接跳到终点。补间 `--xxx` 一律写成 `gsap.fromTo(el, { '--xxx': 起点 }, { '--xxx': 终点 })`。（flat）
- **选择器带上风格。** 每条规则的第一个复合选择器都要有 `[data-scene="<键名>"]`，样册把 15 种风格一起引入，漏了就会染到别的风格。`@font-face` 这类全局规则除外。
- **伪元素再描一遍字时给读屏留空。** 重点词用 `::after{content:attr(data-k)}` 叠一层字时，读屏会把词念两遍：写成 `content:attr(data-k); content:attr(data-k) / "";`（前一句给不认替代文字的老浏览器）。（blueprint，黑板顺手改了）
- **约定的变量照名字用**：署名颜色 `--sign-color`；形象投影 `--mascot-shadow`（一串 drop-shadow，不能写 `none`）、描边 `--mascot-outline`。页面能用的 `--t-*` 卡片颜色要全部给出这种风格的映射，哪怕几个映射到同一种颜色。

## 1.5 可读性（自有版式也要守）

风格自己的版式可以很有个性（竖排手卷、拼贴目录、关卡地图），但翻到每页最后一拍时整页要读得清。写版式组件时先对照 `references/authoring.md` 第 0 节第 9 条的底线，自检会查其中三条（对比度、竖排、讲过的看不见了）：

- **装要点的容器不能只显示最新一句。** 对话框、气泡这类轮换显示的组件只放旁白；要点要落在版面上一直留着（道具格下面、关卡名下面）。组件里的过场字给 `data-transient`。（pixel）
- **竖排只给短字。** 题签、印文、两三列短诗句可以竖排；说明句一律横排。一块不超过 12 个字，一页加起来不超过 24 个字。（ink、magazine）
- **拼贴、错落要有一条阅读路径**，编号就是顺序，别拿页码当编号；文字块倾斜不超过 2°。（magazine）
- **装饰字效（条纹渐变、套印错位、描边空心）只用在 8 个字以内的标题和大数字上。**（pixel、magazine）
- **讲过会变淡的块，背后别垫装饰。** 块淡到 .8 时是半透明的，背后的网点、色块会透出来，看着发脏；自检的对比度只量字，查不到这种情况。装饰挪到块旁边，或者放在第 0 拍不变淡的层里。（magazine）
- **画在 `::before` / `::after` 里的字自检量不到**（比如套印编号），它的对比度和位置只能亲眼看截图。（magazine）
- **比喻旁边写真话。** 关卡、战斗、印章是包装，真实内容要直接写在页上。（pixel）
- **背景网格要对准舞台坐标。** 方格纸、蓝图这类网格，写成从舞台中心偏移的位置（如 `background-position: calc(50% + 24px) calc(50% + 12px)`），舞台坐标 48 的倍数就落在格线上，窗口不是 16:9 时也对得上；页面里的字、框照格线放。（paper）
- **自检时动画是关着的，出场代码要亲眼播一遍。** 自检直接跳到每拍的最终状态，碰不到风格的出场函数：出场里的报错、没清掉的行内样式要在浏览器里连按前进、一路退回才看得出来。（flat、paper、dark）

## 2. gsap

- **引擎：跳拍时时间线被直接推到结尾（`progress(1)`），补间自己 `onComplete` 里的 `gsap.set(el, { clearProps })` 不生效。** 会留下行内的 `opacity:1`，盖住讲过退后的变淡。清内联样式改用 `el.style.removeProperty('opacity')` 这类直接写法。（dark；dark 原有的翻页代码里还有旧写法）

- **位移动画会吃掉 CSS 的 `translate` / `rotate` / `scale`。** gsap 3.13 做位移动画时把这几个独立属性并进 `transform`，并在行内写成 `none`：组件在动画里时，CSS 写的 `translate` 不起作用。要常驻的偏移放在外层包一层，或者整个交给 gsap 的 `x` / `y`。（brutal）
- **退一拍做了旋转，`onBack` 里要 `clearProps`。** gsap 会记住转过的角度，下次出场从那个角度开始，纸条越歪越多。（magazine）
- **引擎：用函数写的出场，结束时引擎不清内联样式。** 风格要自己在时间线末尾清掉（`clearProps` 或 `tl.set(e, { clearProps: '…' })`），不然留在行内的 `opacity` 盖过 `.past` 的变淡，讲过的拍不变淡。（pixel）
- **引擎：`intro` 里调不到引擎内置的出场**（`rise`、`pop` 等），开场要用的动作风格得自己写一份。（magazine）
- **引擎：`enterBy` 只按组件类名匹配**，选不到 `.steps > li` 这种结构，步骤每一项的出场要在 `plan` 或函数出场里自己处理。（pixel）
- **引擎：重点词到拍的放大写死在引擎里**，风格不想要只能在 CSS 里用 `!important` 压掉。（pixel）放大收回后，引擎会把行内的 `transform`、`translate`、`rotate`、`scale` 都去掉（2026-11-18 起），风格给重点词写的 CSS 变换不再被 `none` 盖住。（glass、comic、brutal 发现）
- **退拍清样式时，gsap 记着的位移也一起清了**（2026-11-18 起，引擎的 `clearEl` 会 `clearProps:'transform'`）。以前只清行内样式，之后的出场只补间 x 或 scale 时会把旧的 y 写回去，字低一截。（frost 发现）
- **`ctx.done()` 会掐掉同一个元素上的补间。** 它清内联样式时会 `killTweensOf` 这个元素：函数式出场里提前调用，同一元素上还没播完的补间会被截断。等这个元素的补间都排完、在时间线末尾再调。（comic）
- **引擎：`copied` 结尾的淡出写死是平滑过渡**，逐格风格的「已复制」最后会有一下半透明。（pixel）
- 不许循环动画（形象眨眼、偶尔的小动作、迈步帧除外），单拍内容动效约 1.2 秒以内，减少动态时直接显示。

## 3. 透明度与磨砂

- **外层半透明会让里面的 `backdrop-filter` 失效。** 祖先只要 `opacity < 1`，子孙的磨砂、折射就没了。毛玻璃的做法：讲过的拍变淡时用 `:has` 让孩子各自变淡，外层保持不透明。（frost）
- **翻页、载入的淡入淡出也会暂时去掉折射。** 讲过变淡、翻页淡入淡出、载入淡入时，玻璃都会短暂没有折射，属于已知现象。下一轮可以考虑让风格声明「变淡只作用于子元素」。（glass）
- **贵的效果要能自动关。** 实时折射这类效果，在配置差的电脑上前两次出场量到掉帧就关掉；地址加 `?flat` 能看退化后的样子。不支持 `backdrop-filter` 的浏览器要有退路（比如退成 84% 白底），字照样清楚。（glass、frost）
- **减少动态时 visibility 晚一帧切换。** 刚翻拍就读 `getComputedStyle` 会读到 `hidden`，不影响显示；要量就等一帧。

## 4. mount 时机

- **`intro` 被调用时，外框（主题行、页码、节拍指示）还没刷新。** `go()` 先进页调 `intro`，之后才更新外框，开场时 `.chap span`、节拍指示里的 `.dots i` 这些元素还不存在：要在时间线 0 秒处 `tl.call(…)` 里再去找，别在 `intro` 一进来就查。（comic）
- **`mount` 被调用时，舞台的 `data-scene` 可能还没换上。** 换风格动画时会晚约 0.2 秒，在 `mount` 里量外框会量到没套这种风格样式的尺寸。液态玻璃用 `MutationObserver` 盯着 `data-scene`，换上了再量。（glass）
- 悬停反馈的监听挂在 `mount` 里、在 `unmount` 里摘掉；进阅读模式时引擎会 `unmount`，回来再 `mount`。
- 背景放进 `backdrop(layer)` 给的铺满窗口的背景层，宽屏要延伸到舞台外，不露边。

## 5. 字体

- **风格自带的字体放 `template/vendor/fonts/<键名>/`。** `new` 只在选了这种风格时把整个目录复制进课件；风格 CSS 用 `../vendor/fonts/<键名>/…` 的相对路径引用，许可证放同一个目录。风格 js 一加载就 `document.fonts.load(…)` 让浏览器开始下载。（pixel）
- **引擎会等字体再量。** `core.js` 的 `fontsReady` 先点名加载霞鹜文楷，再等 `document.fonts.ready`（最多约 2.5 秒），然后才量主题行、署名位置和形象落脚点。以前只等霞鹜文楷，风格字体晚到时会按退回的字体量偏，这一条已经改好。
- **字库可能缺字。** 缝合像素字体里没有 `›` 和 `⤢`，像素游戏改成画像素图标。用新字体前把引擎界面里用到的符号查一遍。（pixel）
- **点阵字体的字号用点阵的倍数。** 像素字体是 12px 点阵，字号用 24、48、96 才匀；样板封面 `samples.css` 的 112px 不是 12 的倍数，像素风格下点阵略不匀（不报错）。（pixel）
- **黑体、宋体比楷书宽。** 从手绘家换过来，原来刚好放下的字可能溢出，风格做完要用样册在 5 个尺寸下都跑一遍自检。Windows 自带的宋体笔画细，杂志复古检测到只有细宋体时自动描边加粗。（magazine）
- **引擎：主题行 `fitTopics` 固定从 42px 往下缩。** 风格把主题行 `.tt` 的默认字号改小，放不下时反而会先放大到 42px 再缩，别改小这个默认字号（下一轮引擎可以改成从风格的字号往下缩）。（flat、glass）
- 纯像素课件也加载霞鹜文楷：引擎的提示条、阅读模式还用它，先不改。

## 6. 自检

- **圈注比元素左右各宽约 22px**，会划到旁边的字：被圈的词左右留点空（样板页已用 margin 处理）。
- **禁区写进 `zones`**（舞台坐标）：页码和节拍指示、粉笔槽这类位置和默认差得多的，一定要声明，自检才会报「进了风格的禁区」；同样的数字写进 `styles.md` 的脾气里。背景里很淡、字压上去也看得清的（远山、草坡），不算禁区。
- **测试课件**：建 `test/fixtures/decks/scene-<键名>/`，至少 6 页（封面、清单、横排步骤加箭头、终端加可复制的一行、金句加截图位、一排小格），最后一页有自动署名；`check <目录> --browser` 0 错误。
- **样板页**：样册已经引入全部风格，直接跑 `node skills/li-talk-skills/scripts/li-talk.mjs check skills/li-talk-skills/template --browser --scene <键名>`，4 个样板页 × 5 个尺寸 0 错误。还没合并进样册时，把 `gallery.html` 复制到 `_private/try/` 改路径再跑。
- **兼容课件**：动了引擎就跑一次 `_private/compat/new`（41 页旧课件），错误数应保持不变（现在是 15 个，都是旧课件自己的小字和形象压字）。
- 亲眼看：浏览器 1920×1080 逐页看最后一拍；开场、悬停、点击涟漪、复制反馈各试一次；390×844 阅读模式、减少动态各看一次。

## 7. 合并进共用文件

风格文件、形象、测试课件由写风格的人提交；下面这些共用文件由主会话统一改，写风格的人在报告里给出要加的内容：

- `template/scenes/index.json`：一条 `{ key, label, family, mascot, look, fit, notFit, risk }`，按家排（手绘、现代、像素），`test/new.test.mjs` 里写着完整顺序。
- `references/styles.md`：在对应的家下面加一节（样子、适合、不适合、脾气、默认形象、动效、自带出场名），第 2 节三家的表格补上。
- `scripts/lib/guide.mjs` 的 `HINTS`：5–10 个最能代表这种风格的词；同一个词只归一种风格，也不能是别的风格的词的一部分（`test/guide.test.mjs` 会查）。深色底的风格写 `dark: true`，在投影场合会自动降分。
- `template/gallery.html`：风格 css 放 head，风格 js 在引擎之后、形象 js 在风格 js 之后；`test/gallery.test.mjs` 的 `SCENES` 同步。样板页保持通用，不加只有某种风格认的东西。
- 文档里写着风格个数和形象列表的地方：`SKILL.md`、`references/authoring.md`（形象大小表）、`references/templates.md`、`docs/design.md` 第 6.5 节。
