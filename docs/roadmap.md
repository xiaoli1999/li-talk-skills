## 现在已有的（0.1.0）

- 15 种风格、15 个形象；4 种样板页（封面、清单、步骤、结尾）；最后一页自动署名。
- 课件：按拍出现、讲过的变淡、主题行、一句话解释、重点词、圈注、多种出场、手绘线稿、散落再归位、自定义动画；形象走位、眨眼、悬停、点击反应、空闲小动作、5 分钟打盹；点击复制；截图点开看大图；演讲者视图（S）、计时（T / R）、全屏（F）；彩排模式（演讲者视图里按 H：每页用时、按讲词字数估的建议用时、超时变红、小结可复制给 AI）；总览跳页（O）、黑屏（B 或「.」）、激光笔（L）、底部进度条（按章节分段）；换风格转场；竖屏阅读模式；刷新不丢位置；触屏滑动；减少动态；开场、点击涟漪；`?scene=`、`?mascot=` 临时切换。
- 命令：`guide`、`styles`、`materials`、`new`、`open`、`confirm`、`check`、`check --browser`、`fonts`、`version`、`update`。
- 自动更新：每天第一次运行命令时同时读 GitHub 和 jsDelivr 上主分支（`master`）的 `manifest.json`，只下载变了的文件，在临时目录拼出完整新版、整体校验后整包替换，转述 CHANGELOG 要点；仓库里运行跳过，插件安装的提示 `claude plugin update`；`version` 显示安装位置和上次检查，`update` 立即更新。
- 发版脚本：`build.mjs --manifest`（生成文件清单和校验值）、`--check`（干净度检查：本机路径、内部词、版本号和 CHANGELOG、清单、换行、是否都进了 git）、`--release`（发版前一条龙，含全量测试）。
- 后台自检：5 个尺寸逐页逐拍量溢出、重叠、挡字、禁区、字号、收回、报错，出中文报告，可截图。

## 7. 引擎改进（写风格时发现的）

- 风格自带字体：引擎已改成等 `document.fonts.ready` 再量；可以再给风格加一个「字体」字段，引擎统一管加载。
- 重点词到拍时的放大写死在引擎里，风格只能用 `!important` 关掉；改成风格可以配置。
- `enterBy` 只按类名匹配，选不到 `.steps > li` 这类元素；改成也认选择器。
- 用函数覆盖的出场结束时，引擎不清内联样式，风格要自己清，否则讲过的拍不会变淡；改成引擎统一清。
- 「已复制」提示结尾的淡出写死成平滑淡出；改成风格可以接管。
- `intro` 调用时外框（章节标签、节拍格）还没刷新；调整调用顺序，或在 `ctx` 里给出外框元素。
- 主题行缩字固定从 42px 往下试；改成从风格设定的字号往下试。
- 讲过的拍整块变淡会让里面的磨砂、折射失效（毛玻璃、液态玻璃用 `:has()` 绕开）；给风格一个「变淡只作用于子元素」的选项。
- 视差和帧率保护：现在液态玻璃自己做了帧率保护；改成引擎统一提供，风格声明哪些效果「贵」。
- 样板页整体偏空、投影上字偏小：样板的卡片可以更高、正文更大，或内容整体垂直居中。
- 样册用的是常用字小字库，个别字回退到系统楷体；`styles --open` 时如果本机有完整字体，让样册也用完整字体。
